Четыре эксперимента с ИИ: фильм без камеры, 700 тысяч мазков и японский храм из кода

Четыре визуальных эксперимента: cinecode собирает ролики из программных кадров, Claude имитирует 700 тысяч мазков кисти, авторы сняли ретрофантастику и создали интерактивный японский пейзаж.

Нейросеть научили делать фильмы, в которых каждый кадр нарисован программным кодом.

Разработчик sarpstar выложил на GitHub открытый проект cinecode. Он позволяет поручить создание видеоролика ИИ-агенту в Claude Code или Cursor. Агент пишет сценарий, программирует изображение, создаёт звуковое сопровождение и собирает готовый MP4.

В октябре компания VideoGen показала фильм, собранный нейросетью по одному запросу. Разработчик cinecode предлагает другой подход: ИИ-агент пишет программный код для каждого кадра, управляет движением объектов, камерой и освещением.

По темеОдин запрос — целый фильм: VideoGen показала, как ИИ самостоятельно собирает киноНовости ИИ · 21 октября 2026

Автор предусмотрел два режима. Быстрый рассчитан на короткие ролики, рекламу и объясняющие видео, а второй позволяет поэтапно работать над длинными фильмами. На GitHub опубликованы примеры анимации, документальных и рекламных роликов.

Cinecode доступен с исходным кодом на GitHub. Для работы понадобится агент, способный запускать программы на компьютере, браузер для отрисовки кадров и FFmpeg для сборки видео.

В ноябре энтузиасты уже показывали, как нейросети создают виртуальные компании, игры и целые интерактивные миры. В новой четвёрке экспериментов разработчики сосредоточились на изображениях и кино.

700 тысяч мазков ради одной картинки

Сотрудник Anthropic Джейк Итон дал Claude Fable 5.2 задание нарисовать изображение, максимально похожее на фотографию.

На итоговой картине оказалась тележка на парковке.

Для её создания нейросеть написала программу, которая имитировала примерно 700 тысяч отдельных мазков кисти. Виртуальная краска смешивалась, а щетинки оставляли следы. Каждый мазок рассчитывался программно.

Посмотреть работу Джейка Итона можно вместе с его исходным сообщением от 9 ноября.

В других опытах Итон просил Claude придумывать художников с собственными стилями и писать программы длиной в одну-две тысячи строк для имитации их живописи.

Нейросеть при этом использовалась как программист виртуального живописца. Обычный генератор изображений в описанном эксперименте не применялся.

Восемь с половиной минут фантастики из шестидесятых

Режиссёры Кристофер Гвинн и Питер Хёгучи выбрали другой путь.

15 ноября они представили восьмиминутную первую часть фильма Treasure of the Himalayas, стилизованного под фантастические приключения 1960-х годов с насыщенными цветами Technicolor.

Для создания изображений использовали Midjourney, а видео генерировали через Seedance 2.5 на платформе Dreamina.

Авторы показали готовый восьмиминутный фрагмент и сообщили, что ищут инвесторов для производства полного фильма в 2027 году.

Пока зрителям доступна первая часть. Сам проект задуман как полнометражная картина.

Храм, поезд и птицы без готовых 3D-моделей

Разработчик под именем KANA попросил Claude Fable 5.2 создать интерактивный японский пейзаж.

На экране появился храм, железнодорожный переезд и стая голубей. Если позвонить в колокол, птицы разлетаются. При срабатывании переезда появляется поезд.

По словам автора, все частицы сцены создавались программно, без загруженных фотографий и готовых трёхмерных моделей. Эксперимент использовал технику Gaussian Splatting для изображения объёмного пространства.

Демонстрация пейзажа с храмом и поездом показывает, как сцена реагирует на действия пользователя.

Здесь нейросеть создала программную интерактивную среду, которую можно изменять прямо во время просмотра.
