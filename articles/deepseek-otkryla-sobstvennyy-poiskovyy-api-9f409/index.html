DeepSeek открыла собственный поисковый API

Опубликовано: 19 октября 2026

Одновременно с обновлением модели DeepSeek предоставила разработчикам доступ к собственному поисковому движку.

Новые интерфейсы Search и Fetch позволяют программам искать информацию в интернете и получать содержимое найденных страниц.

По заявлению компании, её поисковая система ежедневно обрабатывает сотни миллионов запросов.

Доступность: оба API открыты для разработчиков. Стоимость каждого — $0,75 за 1000 вызовов.

При использовании серверных инструментов в DeepSeek Harness, Claude Code и Codex поисковые вызовы пока бесплатны для пользователей DeepSeek API. Платная тарификация этих вызовов начнётся 31 октября в 16:00 UTC.

Почему важно: появляется ещё один инструмент, с помощью которого можно создавать ИИ-агентов, самостоятельно ищущих информацию в интернете. Для автоматизированных новостных систем это особенно интересно, хотя качество поиска и достоверность результатов ещё нужно проверять на практике.
