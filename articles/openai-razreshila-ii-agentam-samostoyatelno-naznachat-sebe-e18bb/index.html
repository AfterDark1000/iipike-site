OpenAI разрешила ИИ-агентам самостоятельно назначать себе задания

Опубликовано: 24 октября 2026

ИИ-агенты
Компании и продуктыOpenAI

— систему планирования заданий для Agents API. Она позволяет запускать ИИ-агентов в определённое время или по регулярному расписанию.

Разработчик может заранее настроить автоматические проверки, ежедневные отчёты или другие повторяющиеся действия. Но новая система позволяет передать управление расписанием самому агенту.

Для этого ему нужно предоставить инструмент automations. Получив доступ, нейросеть сможет создавать задания, менять время выполнения, ставить их на паузу и удалять.

Например, агент анализирует работу сервера и замечает нестабильность. Вместо того чтобы ждать следующей команды, он назначает повторную проверку через два часа. Если проблема исчезла, расписание можно отменить.

Предусмотрены два варианта выполнения заданий. Система может каждый раз запускать новую сессию или возвращаться к уже существующей, сохраняя историю работы и предыдущие результаты. Правда, самостоятельно управлять расписанием агент может только в рамках своей текущей сессии.

Такой подход позволяет агентам вести продолжительную работу, не требуя от человека постоянно напоминать о следующем шаге.

Scheduled Automations уже доступна разработчикам через Agents API. Для обычного пользователя ChatGPT это обновление ничего не меняет: речь об инструменте для создания собственных ИИ-систем.
