ChatGPT пустят в бухгалтерию. Oracle доверит ИИ корпоративные дела!

Опубликовано: 28 октября 2026

ChatGPT скоро сможет залезть в корпоративную бухгалтерию, проверить закупки и выяснить, почему компания потратила больше запланированного.

27 октября OpenAI и Oracle объявили о расширении сотрудничества. Компании собираются подключить ChatGPT к корпоративным приложениям и базам данных Oracle, которыми пользуются бухгалтеры, финансисты и руководители.

Для этого Oracle разрабатывает AI Workspace — рабочую среду, объединяющую ChatGPT с внутренними системами компании.

Например, сотрудник сможет попросить нейросеть разобраться в расходах отдела, проверить закупки или подготовить информацию для закрытия месяца. Вместо ручного поиска по нескольким программам ChatGPT соберёт нужные сведения и поможет выполнить разрешённые действия.

Доступ к информации и операциям будет зависеть от полномочий сотрудника. Если человеку запрещено изменять финансовые документы, нейросеть не должна получать таких прав за него.

Параллельно Oracle представила ещё несколько инструментов.

App Composer позволит создавать корпоративные приложения с помощью Codex. Oracle возьмёт на себя их размещение в облаке и управление доступом.

AI Security Mesh предназначен для поиска уязвимостей в корпоративных программах и инфраструктуре. А для малого бизнеса подготовили комплект с ChatGPT, Codex, приложениями Oracle и облачными ресурсами.

У самих разработчиков Oracle нейросети уже работают вовсю.

Компания сообщила о 130 тысячах активных пользователей ChatGPT и более 95 тысячах пользователей Codex. По её данным, исследование рынка, на которое у сотрудников отдела найма раньше уходило два–четыре дня, теперь подготавливается за 15–20 минут.
