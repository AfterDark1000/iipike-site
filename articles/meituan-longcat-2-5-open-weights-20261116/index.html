Китайцы открыли ИИ на 1,6 триллиона параметров. Он работает на чипах Huawei

Meituan открыла веса LongCat-2.5 с 1,6 трлн параметров под MIT. Модель поддерживает программирование, мультимодальные задачи и оптимизированную конфигурацию W4A4 для Huawei Ascend.

Китайская компания, известная доставкой еды, выложила в открытый доступ нейросеть размером 1,6 триллиона параметров.

Meituan открыла веса модели LongCat-2.5 под лицензией MIT. Разработчики могут скачивать её, изменять и использовать в собственных проектах, в том числе коммерческих.

Сама модель появилась через API ещё 2 ноября, а к середине месяца стали доступны её веса и специальная версия для китайских ИИ-ускорителей.

1,6 триллиона параметров, но работают не все

LongCat-2.5 использует архитектуру Mixture of Experts, или «смесь экспертов». При обработке каждого фрагмента текста задействуется примерно 48 миллиардов параметров из общих 1,6 триллиона.

В конце октября французская Mistral уже открыла модель примерно на триллион параметров. Китайская разработка крупнее по общему числу параметров.

По темеMistral выложила ИИ на ТРИЛЛИОН параметров!Новости ИИ · 30 октября 2026

LongCat-2.5 рассчитана прежде всего на программирование и работу ИИ-агентов. Она может разбирать большие проекты, писать и исправлять код, использовать инструменты и выполнять многоэтапные задания.

Модель также понимает изображения и видео. Разработчик может передать ей изображение интерфейса и попросить написать для него программу.

Через официальный API доступен контекст до миллиона токенов. Это объём текста и других данных, который модель способна учитывать в пределах одного запроса.

Китайские процессоры вместо NVIDIA

Для LongCat-2.5 разработчики подготовили версию с четырёхбитным представлением весов и вычислений, обозначенную W4A4.

Она предназначена в том числе для китайских ускорителей Huawei Ascend. В опубликованных материалах Meituan описывает развёртывание на таких процессорах и оптимизации для уменьшения объёма вычислений и обмена данными.

По внутренним измерениям компании, четырёхбитная версия обеспечивает на 43,3% более высокую скорость обработки входных данных по сравнению с восьмибитной конфигурацией W8A8.

Для самостоятельного запуска потребуется серверная инфраструктура с большим объёмом памяти.

Результаты испытаний

В тесте Terminal Bench 2.1, где ИИ-агент выполняет задания в терминале, Meituan получила 88,4%.

В опубликованной компанией таблице GPT-5.5 набирает 83,2%, GPT-5.6 Sol — 88,8%, а Claude Opus 5 — 89,1%.

Это результаты сравнительной таблицы Meituan. На других испытаниях LongCat-2.5 уступает некоторым конкурентам.

LongCat-2.5 доступна через официальный API и веб-чат. Открытые веса размещены на Hugging Face.
