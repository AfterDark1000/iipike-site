Тысяча нейросетей работает над одной задачей. Каждая самостоятельно выбирает себе участок работы, обменивается находками с коллегами и проверяет чужие результаты. А руководителя, который раздаёт поручения, вообще нет.

24 октября Microsoft Research объявила об открытии исходного кода Agensh

— платформы, позволяющей объединять до 1024 ИИ-агентов для совместной работы.

Вместо центрального управляющего агента, который должен следить за всеми остальными, участники команды сами находят свободные задания и берутся за их выполнение.

Для координации используются общее рабочее пространство, система сообщений и память, доступная всей команде. В исследовательской реализации эти функции обеспечивают Gitea, Mattermost и отдельный механизм хранения контекста.

Если один агент нашёл полезное решение, остальные могут использовать его результаты. Если кто-то ошибся, другой агент может проверить работу и предложить исправление. Выполненные части объединяются в общий результат.

А тысяча нейросетей действительно работает лучше одной?

Microsoft проверяла Agensh на сложных задачах программирования. Агентам предлагали восстановить работу существующих программ по описаниям и наблюдениям за их поведением. На каждое испытание давалось шесть часов, без доступа к интернету.

В одном из тестов, посвящённом программе Pandoc, использовали модель GPT-5.6 Sol.

Один агент успешно проходил 33,89% проверок. Команда из 128 агентов — 50,94%. А при увеличении числа участников до 1024 результат достиг 55,06%.

То есть тысяча агентов действительно справилась лучше одиночки, хотя прирост от дополнительных участников постепенно уменьшался.

В другом эксперименте исследователи использовали GPT-6.1 Sol. Команда из 32 агентов достигла 79,59% успешных проверок против 56,19% у одного агента.

Agensh распространяется бесплатно под лицензией MIT. Однако это инструмент для разработчиков, а не готовая программа, в которой достаточно нажать кнопку «Запустить тысячу агентов». Для работы потребуются настроенное окружение Linux с Docker и доступ к подходящим ИИ-моделям.
