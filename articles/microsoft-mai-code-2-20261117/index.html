Microsoft заявила, что её ИИ-программист почти сравнялся с Claude Opus при затратах в 20 раз ниже

Microsoft представила MAI Code 2 и MAI Code 2 Flash для программирования в GitHub Copilot. По четырём тестам компании MAI Code 2 достигла 96% результата Claude Opus 5.5 при 5% затрат с учётом временной скидки.

Microsoft AI — Introducing MAI Code 2 and MAI Code 2 Flash (17 November 2026) ↗

Microsoft утверждает, что её новая нейросеть MAI Code 2 выполняет задачи программистов почти на уровне Claude Opus 5.5, расходуя всего 5% его стоимости.

Модель представили 17 ноября на конференции Ignite вместе с облегчённой версией MAI Code 2 Flash. Обе уже подключили к GitHub Copilot — ИИ-помощнику для программистов.

Основная модель рассчитана на сложную работу с кодом: искать и исправлять ошибки, менять сразу несколько файлов, разбираться в больших программных проектах и создавать пользовательские интерфейсы. Flash предназначена для более коротких и частых поручений.

Откуда взялась двадцатикратная экономия

Microsoft сравнила MAI Code 2 с конкурентами на четырёх тестах программирования: DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas и FrontierCode v1.1.

По средним результатам компания получила 96% качества Claude Opus 5.5 при 5% затрат на выполнение заданий. По отношению к GPT-6.1 Sol новая модель достигла 98% результата при 40% стоимости.

В этих расчётах использована временная скидка Microsoft в 50%.

До 17 мая 2027 года миллион входных токенов MAI Code 2 стоит $0,50, выходных — $2,50. Для сравнения, у Claude Opus 5.5 тарифы составляют $4 и $20 соответственно.

Обычная цена токенов сейчас ниже в восемь раз. Двадцатикратная экономия получилась при выполнении тестовых заданий с учётом расхода токенов.

MAI Code 2 сравнивали с GPT-6.1 Sol, хотя 17 ноября OpenAI уже выпустила GPT-6.2 Sol. Результатов сопоставления с новой версией Microsoft не привела.

А как насчёт реальных программ?

В отдельной проверке Microsoft попросила оценщиков вслепую сравнить интерфейсы, созданные MAI Code 2 и GPT-6 Sol.

В 64% сравнений они предпочли результат Microsoft. Всего в оценке участвовали 258 человек, а задания включали веб-интерфейсы, игры, графики, трёхмерные сцены и SVG-изображения.

Для повседневной работы Microsoft подготовила MAI Code 2 Flash. В трёх тестах она показала сопоставимые результаты с GPT-6 Luna и Claude Haiku 5.5, затрачивая соответственно 65% и 20% их стоимости.

Кто уже может попробовать

MAI Code 2 доступна в GitHub Copilot на платных тарифах Pro, Pro+, Max, Business и Enterprise.

Облегчённая MAI Code 2 Flash дополнительно указана среди доступных моделей для Copilot Free и Student. GitHub отдельно оговаривает условия допуска для подходящих пользователей годовых планов, а корпоративные администраторы могут управлять доступом сотрудников к новым моделям.

Выбрать модели можно в поддерживаемых редакторах кода, Copilot CLI, приложении GitHub Copilot и на сайте GitHub. В Microsoft Foundry версия Flash пока находится в ограниченном предварительном доступе.

Microsoft также планирует вывести модели на OpenRouter, Vercel, OpenCode, Hermes и Kilo.
