DeepSeek разрешила создать своего ИИ-помощника

DeepSeek открыла разработчикам API для веб-поиска, чтения файлов и ссылок, распознавания речи и озвучивания. Появился и открытый демонстрационный чат-клиент.

DeepSeek API — обновление инструментов, 13 ноября 2026 ↗

DeepSeek 13 ноября открыла разработчикам функции своего чат-бота: поиск в интернете, чтение документов и сайтов, распознавание речи и озвучивание ответов. Теперь эти возможности можно подключать к сторонним приложениям через API — интерфейс, позволяющий одной программе обращаться к другой.

Раньше разработчик, желавший создать полноценного ИИ-помощника на базе DeepSeek, должен был самостоятельно подбирать и подключать часть дополнительных инструментов. Теперь компания предлагает готовый набор.

Поиск, документы и разговоры

Новые функции работают с моделью DeepSeek V4.1-Flash, которая доступна разработчикам под именем `deepseek-flash`.

Ей можно поручить найти свежую информацию в интернете, открыть несколько страниц, изучить PDF или документ Word. В режиме глубокого размышления модель самостоятельно выполняет последовательные поисковые запросы и читает найденные материалы по ходу решения задачи.

При этом организацию поиска и передачу найденных данных нейросети берут на себя серверы DeepSeek. Разработчику достаточно включить соответствующие возможности в запросе.

Отдельные инструменты позволяют распознавать текст на изображениях (OCR), превращать голосовые записи в текст (ASR) и озвучивать написанное (TTS).

У голосовых функций есть ограничения. Например, в официальном списке языков синтеза речи пока нет русского.

Свой DeepSeek за несколько настроек

Одновременно компания выложила **открытый демонстрационный чат-клиент**. Он показывает, как объединить новые функции в одном приложении: общаться с нейросетью, загружать файлы, искать информацию и использовать голос.

Есть даже импорт истории переписки из обычного DeepSeek. Демонстрацию можно открыть в браузере, указав собственный API-ключ. По заявлению компании, ключ, переписки и загруженные изображения хранятся локально в браузере.

За расширенные возможности придётся платить отдельно. Например, тысяча успешных поисковых запросов стоит $0,75, распознавание тысячи страниц — $0,225. Голосовые инструменты сейчас предлагаются со временной скидкой 50%. К этому добавляется стоимость работы самой языковой модели.

DeepSeek также требует включать проверку безопасности в публичных приложениях. Ответственность за модерацию и соблюдение требований к ИИ-контенту остаётся на разработчиках.

Компания уже открывала собственный поисковый API. Ноябрьское обновление расширяет его до набора инструментов, из которых разработчики могут собрать чат-бота с возможностями, близкими к официальному приложению DeepSeek.
