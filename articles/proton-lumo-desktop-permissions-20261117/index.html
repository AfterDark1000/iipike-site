Proton: Lumo Desktop ↗

По умолчанию новый ИИ-помощник Proton может даже удалять письма из подключённого почтового ящика без ведома владельца.

17 ноября швейцарская компания Proton выпустила Lumo Desktop для Windows, macOS и Linux. Нейросеть умеет работать с файлами на компьютере, выполнять системные команды, подключаться к электронной почте, Google Drive и другим сервисам.

При подключении можно самостоятельно распределить полномочия ИИ:

  • Разрешить — выполняй самостоятельно.
  • Согласовать — сначала спроси меня.
  • Запретить — даже не трогай.

Настраивается каждое действие отдельно. Например, читать входящие письма можно сколько угодно, отправлять только с согласия владельца, а удалять вообще нельзя.

Днём ранее Apple добавила выборочные разрешения для ИИ-агентов на Mac на уровне операционной системы.

Можно даже составить рабочий график

Поручите Lumo каждое утро разбирать почту и к началу рабочего дня готовить список писем, требующих ответа. У каждого задания по расписанию будут собственные права доступа.

Появились и так называемые Skills (навыки). В них можно хранить инструкции, образцы документов, шаблоны и даже примеры собственного стиля переписки, чтобы каждый раз не объяснять нейросети, как именно нужно выполнить работу.

Исходный код приложения открыт. Proton утверждает, что содержимое переписок и данные из подключённых сервисов не используются для обучения ИИ и персонализации рекламы.
