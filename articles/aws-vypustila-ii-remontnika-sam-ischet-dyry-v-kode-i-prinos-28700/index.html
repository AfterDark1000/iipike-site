Сканер безопасности обнаружил тысячу уязвимостей. Отлично, спасибо. Теперь осталось выяснить, через какие из них действительно можно взломать систему, а какие просто пугают красными предупреждениями.

И желательно всё это исправить, пока хакеры не заинтересовались первыми.

22 октября 2026 года Amazon Web Services запустила AWS Continuum for Code Vulnerabilities

— сервис, который проверяет уязвимости, оценивает возможный ущерб и самостоятельно готовит исправления.

Программисту остаётся проверить результат и решить, можно ли доверить этому электронному ремонтнику собственный код.

Нашёл дыру? Докажи, что через неё можно пролезть

Обычные сканеры безопасности способны выдавать огромные списки потенциальных проблем. Но высокая оценка опасности ещё не означает, что злоумышленник действительно сможет воспользоваться уязвимостью.

Например, одна ошибка находится в забытом тестовом инструменте, недоступном извне. Другая — в работающем сервисе, через который можно добраться до базы клиентов.

По формальной оценке первая может выглядеть страшнее. По реальным последствиям опаснее окажется вторая.

Continuum пытается разобраться именно с этим.

Система изучает код приложения и, если подключены соответствующие данные AWS, его облачную инфраструктуру: сетевые соединения, права доступа, зависимости между сервисами и расположение важных ресурсов.

Затем проверяет, насколько реальна угроза. Иногда достаточно анализа исходного кода. В других случаях ИИ воспроизводит эксплуатацию уязвимости в изолированной среде, чтобы подтвердить возможность атаки.

Заодно оценивает, насколько далеко злоумышленник сможет продвинуться после успешного взлома и смогут ли существующие средства защиты его остановить.

Вместо очередного красного предупреждения разработчик получает объяснение: где находится проблема, как её можно использовать и до каких данных способен добраться атакующий.

А заплатку кто принесёт?

Тоже Continuum.

После подтверждения проблемы сервис предлагает изменить код, обновить уязвимую зависимость или поправить конфигурацию.

Затем создаёт pull request в GitHub — готовое предложение изменений, которое разработчик может проверить и добавить в проект.

В демонстрации AWS ИИ подготовил исправление для сервиса корзины интернет-магазина. Оно затронуло четыре файла: 50 строк добавлено, 24 удалено.

К предложению прилагались объяснение уязвимости, оценка риска и результаты проверки.

Правда, кнопка окончательного утверждения осталась у человека.

Вопрос цены

Continuum уже доступен в двух регионах AWS: Северная Вирджиния и Орегон.

Для работы нужно подключить репозиторий GitHub или исходный код через Amazon S3. Анализ можно запускать по расписанию.

Платить придётся за объём защищаемого кода и вычисления, потраченные на анализ.

По тарифам AWS, обслуживание контекста для первого миллиона строк кода стоит $200 в месяц, а каждая специальная вычислительная единица Continuum — ещё $10.

В собственном расчётном примере Amazon защита миллиона строк с обработкой 100 уязвимостей обходится в $1200 за месяц.

Так что сервис явно ориентирован прежде всего на компании, у которых много кода, сложная инфраструктура и достаточно проблем с безопасностью, чтобы автоматизация окупалась.
