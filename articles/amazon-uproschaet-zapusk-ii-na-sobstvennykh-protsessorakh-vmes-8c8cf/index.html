Amazon упрощает запуск ИИ на собственных процессорах вместо NVIDIA

Опубликовано: 20 октября 2026

Amazon представила TorchNeuron — инструмент, позволяющий запускать программы для машинного обучения на процессорах AWS Trainium без существенной переделки существующего кода PyTorch.

Раньше перенос моделей между разными аппаратными платформами мог требовать серьёзной переработки программ.

Теперь Amazon пытается убрать этот барьер.

Суть дела: одна из причин доминирования NVIDIA — не только мощные видеокарты, но и программная экосистема. TorchNeuron может упростить использование альтернативного оборудования.

Доступность: анонс опубликован 19 октября. Открытая бета запланирована на 20 октября 2026 года. Код будет распространяться по лицензии Apache 2.0. Поддерживаются Trainium2 и Trainium3.
