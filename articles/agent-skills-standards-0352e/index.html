Anthropic больше не рулит Agent Skills в одиночку — теперь в деле конкуренты

Опубликовано: 23 октября 2026

ИИ-компании готовы бесконечно выяснять, чья нейросеть круче, но когда дело дошло до общих стандартов, оказалось, что каждому городить собственный огород довольно глупо.

22 октября Anthropic передала Agent Skills под управление Agentic AI Foundation, действующего при Linux Foundation.

Теперь развивать стандарт будут в том числе конкуренты Anthropic — разработчики ChatGPT, Gemini и других ИИ-систем.

Папка, которая учит нейросеть работать

Допустим, вы наняли нового сотрудника. Он толковый, быстро учится, но понятия не имеет, где лежат документы, как оформлять отчёты и почему бухгалтерия приходит в ужас от ваших таблиц.

С ИИ-агентами похожая история. Даже способной нейросети нужно объяснить, как выполнять конкретную работу.

Для этого и существуют Agent Skills — папки с файлом SKILL.md, в котором описаны необходимые действия. Рядом могут лежать шаблоны, справочники и готовые программы.

Например, редакция может создать навык для подготовки новостей: искать первоисточники, проверять цифры, соблюдать авторский стиль и не начинать каждую статью словом «Представьте».

Последнее некоторым нейросетям стоило бы прописывать особенно крупным шрифтом.

Подготовленный навык можно переносить между совместимыми ИИ-системами, вместо того чтобы каждый раз собирать рабочий процесс заново.

Миллион навыков. Кто все эти люди?

Anthropic открыла Agent Skills в декабре 2025 года. За несколько месяцев формат расползся далеко за пределы Claude.

По данным компании, его уже поддерживают более 70 платформ, включая ChatGPT, Cursor, GitHub Copilot и VS Code.

В каталоге skills.sh опубликовано свыше миллиона навыков, а количество установок приближается к 280 миллионам.

Конечно, один разработчик может скачать хоть сотню навыков. А среди миллиона папок наверняка найдутся такие, которые лучше бы никому не открывать. Качество каждой из них Anthropic не гарантирует.

Стандартом пользуются конкурирующие компании, а распоряжалась им до сих пор одна Anthropic. Теперь управление переходит независимому фонду.

Компания передала ему название Agent Skills, логотип, домен agentskills.io и организацию проекта на GitHub.

За дальнейшее развитие будет отвечать технический комитет с участием инженеров Anthropic, OpenAI, Google и других организаций.

А пользователям теперь что делать?

Паниковать.

Шутка.

Ничего не делать. Или радоваться тихонько.

Существующие навыки продолжат работать, стандарт остаётся открытым, платить за его использование не требуется.

Создавать собственные навыки можно по-прежнему.

Только совместимость не волшебная. Если для выполнения задачи нужна программа, которой у агента нет, никакой SKILL.md её не материализует. А запрещённый доступ к файлам от появления навыка разрешённым не станет.

С безопасностью тоже придётся разбираться. В скачанных навыках могут находиться исполняемые скрипты. Запускать неизвестный код с доступом к рабочим документам — примерно как пустить случайного прохожего в офис и сразу выдать ему ключи от сейфа.
