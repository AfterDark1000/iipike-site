OpenAI выпустила Images 2.6: ChatGPT теперь делает ГИФКИ!

OpenAI выпустила Images 2.6: ChatGPT получил создание GIF и более точное редактирование изображений, а API — варианты Flare и Sunburst.

Опубликовано: 5 ноября 2026

OpenAI — Introducing Images 2.6, 4 ноября 2026 ↗

OpenAI 4 ноября представила Images 2.6. По заявлению компании, генерация изображений стала на 50% быстрее, а ChatGPT научился создавать анимированные GIF по текстовому описанию или из готовых картинок. Заодно разработчики улучшили редактирование: модель должна лучше сохранять персонажей, предметы и другие детали при последовательных правках.

Для создания GIF достаточно описать, что должно двигаться. Можно оживить нарисованного персонажа, сделать зацикленную анимацию из фотографии или подготовить короткую сцену для соцсетей. Готовую анимацию можно редактировать, менять скорость воспроизведения и сохранять.

Другая часть обновления касается знакомой проблемы генеративной графики: просишь изменить одну деталь, а нейросеть заодно перерисовывает половину изображения.

Images 2.6 лучше удерживает внешность персонажей, особенности товаров и фирменные элементы при повторных изменениях. Это особенно полезно при подготовке серии иллюстраций, рекламных материалов и изображений с постоянными героями.

Сохранение неизменённых деталей при редактировании становится отдельным направлением развития генеративной графики. Ранее мы рассказывали о Fibo 2.0 от Bria, где разработчики тоже сосредоточились на точечных правках изображений.

Две модели и новые инструменты для разработчиков

В API появились два варианта:

  • GPT-Image-2.6 Flare ориентирована на скорость. При низких настройках качества генерация может занимать всего шесть секунд.
  • GPT-Image-2.6 Sunburst рассчитана на более детальные изображения и сохранение согласованности при редактировании. Для таких задач предусмотрены средние и высокие настройки качества.

Разработчики также получили возможность точно указывать области изменений с помощью разметки изображения, экспортировать графику в SVG и управлять сложностью обработки запроса.

Последний параметр определяет, сколько усилий модель потратит на планирование изображения. Простую правку можно выполнить быстрее, а для сложной композиции выбрать более тщательную обработку.

Заявленные 50% ускорения и шестисекундная генерация — показатели OpenAI. Скорость конкретной задачи зависит от выбранной модели, качества и сложности изображения.

Images 2.6 доступна по всему миру в ChatGPT и Codex на всех уровнях подписки, включая бесплатный. Функция создания GIF появляется у пользователей поэтапно. Flare и Sunburst доступны разработчикам через API с отдельной тарификацией.
