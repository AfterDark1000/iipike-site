Codex так разогнал разработку, что OpenAI пришлось создавать новый Git-сервер

Опубликовано: 3 ноября 2026

Первоисточник

OpenAI — Scaling Git at OpenAI ↗

Программисты OpenAI стали настолько активно использовать Codex, что прежняя инфраструктура хранения исходного кода начала захлёбываться от нагрузки. Отправка изменений замедлялась, возникали ошибки при объединении кода, а надёжность системы временами падала ниже 90%.

2 ноября OpenAI рассказала о Pando — новом серверном движке для Git, который теперь обслуживает основной репозиторий компании.

Почему Git перестал справляться

Git хранит исходный код программ и историю всех изменений. Когда несколько разработчиков работают над одним проектом, он помогает объединять их работу.

Codex резко увеличил количество одновременно выполняемых задач: один инженер теперь может поручить агентам сразу несколько изменений, отправить их на проверку и запустить автоматические тесты.

Каждая такая операция порождает новые обращения к репозиторию. Агенты отправляют код, тестовые системы скачивают изменения, другие агенты получают обновлённые версии. Прежняя инфраструктура OpenAI перестала справляться с этим потоком.

Pando позволяет независимо обрабатывать изменения в разных ветках проекта. Для скачивания кода система повторно использует уже подготовленные и сжатые наборы файлов, которые раздаются через кеширующие серверы.

Так множество клиентов могут получать одинаковые данные без постоянной повторной обработки.

Почти в пять раз быстрее и петабайт данных в сутки

После перехода на Pando медианная задержка отправки изменений сократилась почти на 80%. Это примерно пятикратное ускорение.

Теперь система передаёт клиентам около петабайта Git-данных в сутки, а в один из часов пиковая нагрузка превысила 57 терабайт.

С похожей проблемой столкнулась и Anthropic.

В октябре компания рассказала о Scion — собственной системе контроля версий, которую создали из-за резкого роста объёмов кода, генерируемого Claude. С мая по сентябрь количество ежедневно объединяемых изменений выросло с 2500 до более чем 30 тысяч. Anthropic за пять месяцев полностью перешла с Git на Scion, тогда как OpenAI сохранила привычные команды и протокол Git, заменив серверную часть.

Codex помог построить инфраструктуру для самого себя

Саму Pando тоже разрабатывали с помощью Codex.

Основную архитектуру спроектировал один инженер, большую часть реализации выполнили команды ИИ-агентов, а развёртыванием занималась небольшая группа сотрудников.

От начала разработки до запуска в рабочей среде прошло всего десять недель. Pando начала обслуживать реальные запросы ещё в апреле 2026 года.

Система написана на Rust. Для проверки её надёжности разработчики использовали автоматические тесты и формальные методы проверки алгоритмов.

Агенты на базе GPT-6 Astra помогали искать ошибки, в том числе составляя математические описания поведения Pando на языках Lean и TLA+.

Привычные команды Git для разработчиков сохранились. OpenAI заменила серверную инфраструктуру, одновременно продолжая улучшать сам Git. Часть исправлений уже передана в открытый проект, а возможность поделиться технологиями Pando с внешними пользователями компания пока изучает.
