OpenAI — ChatGPT Enterprise available on AWS Marketplace, 9 November 2026 ↗

OpenAI 9 ноября начала продавать корпоративную версию ChatGPT Enterprise через Amazon Web Services (AWS). Теперь крупные компании смогут покупать ChatGPT там же, где оплачивают серверы, хранилища данных и другие облачные услуги.

Для бизнеса это удобнее, чем кажется. У многих крупных клиентов Amazon есть долгосрочные договоры: компания обязуется потратить на облачные услуги определённую сумму, а взамен получает скидки и особые условия.

Теперь в этот бюджет можно включить и ChatGPT Enterprise. Например, если организация обязалась потратить на услуги AWS миллион долларов, подходящие расходы на корпоративный ChatGPT тоже могут пойти в зачёт этой суммы. Всё зависит от условий конкретного договора.

Покупка оформляется через AWS Marketplace — магазин программ и сервисов для бизнеса. Компании могут использовать привычную систему закупок и получать счета через AWS.

Сам ChatGPT Enterprise остаётся прежним. Сотрудники получают доступ к корпоративному ChatGPT, инструментам программирования Codex и другим возможностям OpenAI. Обновления будут выходить одновременно для клиентов Amazon и тех, кто покупает подписку напрямую.

Для разработчиков у Amazon уже есть сервис Bedrock, через который можно подключать модели OpenAI к собственным программам. Теперь к нему добавился готовый ChatGPT для сотрудников компаний.

Цену OpenAI публично не называет. Стоимость ChatGPT Enterprise согласовывается индивидуально — для покупки нужно обратиться к представителю OpenAI или AWS.
