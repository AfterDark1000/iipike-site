Новости ИИ

Для GPT-6 Luna придумали работу без болтовни. Решения — до 10 раз быстрее

Опубликовано: 23 октября 2026

ИИ-агенты

У ИИ-агентов появилась отдельная профессия: быстро решать, что делать дальше, и не разводить философию на три страницы.

22 октября 2026 года OpenAI объявила о полноценном запуске Decisions API

— специального интерфейса для принятия коротких решений внутри приложений и ИИ-агентов.

Компания утверждает, что он работает до десяти раз быстрее, чем обычный Responses API с той же моделью GPT-6 Luna.

Думай быстрее, говори меньше

Разработчик заранее задаёт возможные варианты ответа и передаёт нейросети необходимую информацию.

Decisions API умеет возвращать три типа результатов:

Выбор: продолжить работу, повторить попытку или передать задачу человеку. Вероятность: например, насколько вероятно, что товар на фотографии повреждён. Оценку: насколько серьёзна обнаруженная проблема по заданной шкале.

Вместо привычного текста приложение получает результат, который можно сразу использовать в программе.

Причём за один запрос разрешается задать до 400 вопросов. Во время публичного бета-тестирования предел составлял 200.

Звучит довольно скромно на фоне нейросетей, которые пишут программы, анализируют исследования и пытаются заменить целые отделы.

Но автономный агент может сотни раз за рабочий процесс выбирать следующее действие. И если каждый такой выбор занимает лишнюю секунду, вся автоматизация начинает двигаться с грацией перегруженного офисного принтера.

А десятикратное ускорение настоящее?

Это заявленный OpenAI максимальный показатель при сравнении Decisions API с обычным Responses API на GPT-6 Luna. Конкретная скорость зависит от задачи.

Компания приводит результаты клиентов, которые уже попробовали новую систему.

В Box, например, выбор маршрута обработки документов оказался примерно в пять раз быстрее при той же точности — по результатам проверки 30 страховых сертификатов.

Разработчик языкового приложения Speak сообщил о сокращении времени до следующего действия голосового помощника с 1,4 до 0,13 секунды.

Теперь ИИ может принимать решения прямо во время разговора

Decisions API встроили в GPT-Live — технологию голосового общения с нейросетями.

Пока человек говорит, приложение может определять, следует ли задать уточняющий вопрос, передать разговор оператору или выполнить другое предусмотренное действие.

OpenAI даже предлагает управлять мимикой виртуального собеседника. Нейросеть оценивает происходящее и выбирает подходящую эмоцию для анимированного лица.

То есть ИИ теперь может успеть сделать удивлённые глаза ещё до того, как пользователь закончит рассказывать о своей проблеме.

Сколько стоит заставить GPT помолчать?

$0,10 за миллион входных токенов. При использовании сохранённого контекста чтение из кеша обходится в $0,01 за миллион токенов.

За выходные токены OpenAI отдельную плату не берёт. Для некоторых способов обработки и кеширования действуют дополнительные тарифные условия.

Decisions API уже общедоступен разработчикам. Он принимает текст, изображения и структурированные данные JSON. Пока поддерживается только GPT-6 Luna.

В обычном ChatGPT отдельной кнопки для этой функции нет. Это инструмент для тех, кто создаёт собственные приложения.
