Павел Дуров решил собрать конкурирующие нейросети под одной крышей. Причём не покупать их, а предложить пользователям самостоятельно подключать любимый ИИ к Telegram.

23 октября в бета-версии Telegram для macOS 13.1.0 обнаружили новую функцию Agent.

Находку опубликовал канал teleLakel, изучающий обновления мессенджера.

В списке уже пять провайдеров: OpenAI (ChatGPT), Anthropic (Claude), Google (Gemini), xAI (Grok) и OpenRouter — сервис, через который можно обращаться к моделям разных разработчиков.

Схема подключения довольно простая. Пользователь выбирает компанию, вводит собственный API-ключ и получает сообщение:

You can now use @agent.

API-ключ — это персональный код доступа, с помощью которого одна программа обращается к нейросети через другую. Например, ChatGPT Plus здесь не поможет: использование API OpenAI оплачивается отдельно от подписки на чат-бота.

Telegram предусмотрел возможность подключать сразу несколько сервисов и переключаться между ними. Настройки будут синхронизироваться между устройствами, а список доступных провайдеров загружается с сервера. Поэтому добавить очередную нейросеть можно будет без обновления приложения.

В коде также нашли поддержку отдельных моделей и поиска по ним, хотя возможность самостоятельно выбирать конкретную модель пока не подтверждена.

А кому достанутся ключи?

При подключении API-ключ проходит через серверы Telegram, где проверяется его действительность. В настройках сохраняются дата подключения и последние четыре символа ключа.

Обладатель действующего API-ключа потенциально может использовать оплачиваемые ресурсы владельца. Как Telegram будет защищать такие ключи, пока неизвестно.

Самое интересное, что Telegram может получить единый интерфейс для конкурирующих нейросетей. Вместо нескольких приложений пользователь сможет выбирать нужный ИИ прямо в мессенджере.

Но до полноценного ИИ-помощника внутри Telegram пока далеко. Неизвестно даже, как именно будет работать @agent: через отдельный чат, внутри переписок или другим способом.
