OpenAI выпустила ИИ для поиска запрещённых изображений детей и ужесточила блокировки ChatGPT

OpenAI представила классификатор для выявления запрещённых изображений с участием несовершеннолетних и объявила о предупреждениях и временной блокировке ChatGPT за нарушения.

Новый ИИ находит запрещённые изображения, которых раньше не было ни в одной базе нарушений.

16 ноября OpenAI представила классификатор для выявления материалов, связанных с эксплуатацией детей, включая изображения, созданные нейросетями. Он анализирует само изображение и отмечает подозрительные материалы для проверки специалистами.

Раньше подобные системы во многом опирались на цифровые отпечатки уже известных изображений. Если кто-то создавал совершенно новую подделку, сравнивать её было не с чем.

Новый классификатор способен обнаруживать и такие случаи.

В собственном испытании OpenAI система отправляла специалистам на проверку на 48% меньше изображений, обнаруживая при этом примерно столько же запрещённых материалов, сколько прежний инструмент.

Доля действительно опасных изображений среди отмеченных классификатором оказалась примерно вдвое выше.

Разработку проводили при участии американского Национального центра по поиску пропавших и эксплуатируемых детей (NCMEC). Доступ к инструменту через API предоставляют бесплатно проверенным организациям, занимающимся защитой детей.

В ChatGPT появятся суточные блокировки

OpenAI также объявила о новых предупреждениях для пользователей, пытающихся получить материалы сексуального характера с изображением несовершеннолетних.

После такого нарушения ChatGPT удалит отмеченный диалог и приостановит доступ на 24 часа.

За повторные нарушения ограничения станут продолжительнее. Возможны окончательное закрытие аккаунта и передача информации правоохранительным органам.

Компания отдельно подчёркивает, что запрет распространяется и на изображения, полностью созданные искусственным интеллектом.

Масштаб проблемы уже отражается в статистике. По данным исследования Childlight, число сообщений об опасном использовании генеративного ИИ против детей выросло в 85 раз за два года.

Для следователей OpenAI подготовила отдельные инструменты анализа материалов расследований. Первый из них помогает разбирать большие массивы переписок, находить связи между событиями и выстраивать хронологию с указанием исходных документов.
