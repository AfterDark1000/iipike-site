OpenAI пообещала разгружать электросети: в Джорджии — до 1000 МВт

Опубликовано: 3 ноября 2026

Будущий дата-центр OpenAI в американском штате Джорджия сможет резко снижать потребление электричества во время жары и других периодов высокой нагрузки на электросеть.

По соглашению с энергетической компанией Georgia Power предусмотрено сокращение потребляемой мощности до 1000 мегаватт.

Для масштаба: столько электричества в среднем требуется примерно 700 тысячам американских домохозяйств.

2 ноября OpenAI объявила программу Grid Protectors

Компания собирается проектировать будущие вычислительные центры так, чтобы энергетики могли временно уменьшать их нагрузку, когда электричество особенно нужно жителям и предприятиям.

Первой площадкой станет вычислительный комплекс в округе Эффингем. Его расчётная потребность составляет 3200 МВт. В периоды пикового спроса энергокомпания сможет сокращать подачу мощности на величину до 1000 МВт — почти на треть.

При необходимости OpenAI также планирует использовать собственные источники энергии и аккумуляторы, чтобы сглаживать перепады потребления.

Соглашение с Georgia Power получило одобрение ещё 26 августа. По его условиям OpenAI оплачивает всю инфраструктуру, необходимую для подключения комплекса. Энергетики рассчитывают, что возможность временно ограничивать столь крупного потребителя позволит сократить расходы на строительство дополнительных электростанций.

Сам дата-центр пока находится в разработке. OpenAI намерена использовать его как первый образец для Grid Protectors, а затем заключать аналогичные соглашения в других регионах США.
