Zoom научил ИИ искать, кто что обещал на совещаниях

Опубликовано: 23 октября 2026

Фраза «я такого не обещал» прекрасно работает, пока никто не хочет пересматривать часовую запись совещания и перелопачивать рабочие переписки.

Zoom решила испортить малину

20 октября 2026 года на конференции Zoomtopia компания представила Unified Context Layer

— систему, которая собирает историю рабочих обсуждений и делает её доступной для ИИ-агентов.

Теперь помощник может искать информацию сразу в расшифровках видеоконференций, телефонных звонках, чатах, документах и подключённых корпоративных приложениях.

Например, сотрудник спрашивает, кто согласовал срок выполнения проекта. ИИ находит соответствующее обсуждение. Затем можно выяснить, что изменилось после разговора с заказчиком и какие задачи остались невыполненными.

Раньше за такими подробностями приходилось ходить по коллегам с вопросом «а мы вообще о чём договорились?». Теперь Zoom предлагает спрашивать у нейросети.

Поиск Agentic Search уже работает с Zoom Meetings, Phone и Chat, а также с более чем 40 сторонними приложениями, включая Google Drive, Microsoft OneDrive, ServiceNow и Workday.

Ответы сопровождаются ссылками на источники. Так что при желании можно проверить, действительно ли кто-то обещал закончить работу к пятнице или ИИ опять нафантазировал.

Начальник у агентов тоже будет

Одновременно Zoom представила ZoomMate Agent Teams — команды специализированных ИИ-агентов.

Вместо одного помощника, которому поручают всё подряд, над задачей могут работать несколько агентов одновременно. Один ведущий агент распределяет работу, а затем собирает полученные результаты для проверки человеком.

И вся эта цифровая бригада может использовать историю проекта из Unified Context Layer.

Zoom уже объявила Agent Teams доступными. А разработчикам открыла Search & Ask API — инструменты, позволяющие получать данные и ответы из корпоративного контекста.

Причём работать с этой информацией смогут и внешние нейросети.

Через API и протокол MCP к данным Zoom можно подключать Claude, ChatGPT, Codex, Gemini и других совместимых ИИ-помощников.

Для API предусмотрены требования к платным тарифам Zoom. Отдельный сервис Ask API требует платной подписки ZoomMate и доступных ИИ-кредитов.

А что с выполнением обещаний?

Здесь Zoom ещё есть над чем поработать.

Компания готовит функцию My Notes Workflows, которая позволит превращать итоги совещаний в реальные действия: отправлять поручения, обновлять записи в Salesforce и создавать автоматические процессы по обычному текстовому описанию.

Её запуск запланирован на октябрь.

В ноябре ожидается расширение протоколов: Zoom собирается связывать показанные во время встречи экраны, слайды и графики с соответствующими моментами разговора.

В декабре должна появиться функция Follow Meeting. Она позволит тем, кто пропустил совещание, получать персональную расшифровку и краткий обзор обсуждения.

Короче говоря, для любителей пообещать на совещании всё что угодно, а через неделю сделать удивлённые глаза, перспективы вырисовываются тревожные.
