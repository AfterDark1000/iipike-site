Куртка меняет цвет прямо во время видео: Higgsfield анонсировала Miracle

Higgsfield анонсировала Miracle — ИИ-технологию для изменения деталей готового видео во время воспроизведения. Пока доступна только партнёрам в закрытом тестировании; интеграция через Higgsfield MCP с Claude запланирована.

Компания Higgsfield 6 ноября анонсировала Miracle — ИИ-технологию, которая позволит редактировать готовое видео прямо во время воспроизведения. Пользователь задаёт изменение, а результат появляется в кадре без ожидания отдельного рендеринга.

Допустим, нужно перекрасить куртку персонажа. Miracle должна изменить её цвет, сохранив исходное движение человека. А если заменить надпись на вывеске, новая надпись будет оставаться на своём месте даже при движении камеры.

Для этого технология преобразует видео в набор редактируемых слоёв. Higgsfield описывает Miracle как систему локальной обработки изображения на уровне пикселей с учётом глубины сцены. Изменения затрагивают выбранную область, а не весь кадр.

Разработчики также обещают управление освещением. Дневную сцену можно будет превратить в вечернюю с соответствующими тенями. Ещё одна возможность — менять свойства материалов: например, длину шерсти животного, сохраняя его движения.

Сейчас подобные операции нередко требуют ручного выделения объектов и отслеживания их перемещения между кадрами. Miracle предлагает заменить значительную часть этой работы текстовыми командами.

Higgsfield планирует подключить Miracle к Higgsfield MCP — интерфейсу для взаимодействия ИИ-помощников с инструментами платформы. Благодаря этому Claude сможет получать задание на редактирование ролика и обращаться к Miracle для выполнения правки.

Публичного доступа пока нет. Miracle проходит закрытое тестирование у отдельных партнёров, а на официальном сайте открыт лист ожидания. Точные показатели скорости обработки и сроки запуска Higgsfield ещё не объявила.
