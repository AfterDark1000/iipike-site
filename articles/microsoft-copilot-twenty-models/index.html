Microsoft открыла «движок» Copilot для 20+ нейросетей!

Опубликовано: 29 октября 2026

Нейросети становятся умнее, но сами по себе они мало что умеют делать за пределами чата. Чтобы ИИ-агент действительно работал, кто-то должен выдавать ему задания, подключать инструменты, сохранять контекст и следить, чтобы он не натворил лишнего.

Microsoft решила поделиться именно этой системой управления.

28 октября компания открыла публичный предварительный доступ к Microsoft Copilot harness через облачную платформу Foundry.

Harness можно представить как диспетчера. Нейросеть решает, что нужно сделать, а система организует её работу: передаёт необходимые сведения, вызывает инструменты, управляет выполнением команд и контролирует установленные ограничения.

Главная ставка Microsoft — на независимость от конкретной нейросети.

Компания заявляет поддержку более 20 передовых моделей. Разработчик может выбирать подходящую модель для задачи, не переписывая каждый раз систему управления. Через SDK также предусмотрено подключение собственных API-ключей провайдеров ИИ.

Для самостоятельного использования доступен SDK — набор инструментов для встраивания системы в приложения. А в Microsoft Foundry можно получить готовую облачную среду, где компания сама обслуживает выполнение задач и изолированное окружение для запуска кода.
