В Южной Корее задержали семерых подозреваемых в массовых взломах с использованием искусственного интеллекта.

По версии полиции, группа проникла в системы более 90 организаций и похитила 8,2 миллиона записей с персональными данными и внутренними документами.

Среди пострадавших — больницы, университеты, частные учебные заведения, гольф-клубы и крупные компании.

26 октября полиция Сеула раскрыла подробности расследования. Главным фигурантом оказался 32-летний мужчина, который самостоятельно изучал взлом сайтов, а затем несколько лет работал в компании по кибербезопасности, занимаясь проверкой защищённости чужих систем.

Впоследствии полученные навыки пригодились ему для совсем других целей.

Поначалу подозреваемый использовал обычные программы для поиска уязвимостей. Но в конце августа 2026 года подключил к атакам ИИ-инструменты, включая ARTEX — систему, способную самостоятельно подбирать средства для проникновения в компьютерные сети.

После этого масштаб атак резко вырос. По данным следствия, с помощью ИИ злоумышленник атаковал ещё около 60 организаций.

Похищенные данные использовались для вымогательства. Представителям компаний отправляли сообщения с угрозами раскрыть информацию, испортить репутацию и привлечь внимание контролирующих органов.

С 38 организаций потребовали в общей сложности 360 млн вон — около $270 тысяч. Однако, по установленным полицией данным, деньги перечислила только одна компания: 300 тысяч вон, чуть больше $200.

Руководитель группы находится под стражей, остальные шестеро проходят по делу без заключения под стражу.

Полицейские тоже использовали собственный ИИ.

Для анализа огромного количества записей соединений и других цифровых следов они разработали отдельную систему, работающую внутри защищённой сети.

С её помощью следователи обработали материалы дела и установили причастных к атакам.
