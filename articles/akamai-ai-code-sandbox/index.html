Akamai заперла код ИИ-агентов в песочнице!

Опубликовано: 28 октября 2026

ИИ-агенты
Компании и продуктыAkamai

ИИ-агент написал программу и решил её запустить. А вдруг в коде ошибка? Или он попытается отправить куда-нибудь чужие данные?

Компания Akamai предложила решать такие проблемы заранее: запускать созданный агентом код в отдельной изолированной среде, откуда нельзя просто так выбраться наружу.

27 октября Akamai представила два сервиса — Agent Sandbox и Inference.

Agent Sandbox работает по принципу песочницы. Сам агент запускается в защищённой среде WebAssembly, а написанный им код получает дополнительный уровень изоляции.

Разработчики могут ограничить потребление памяти, вычислительных ресурсов и доступ к системным функциям. Подключение к внешнему интернету по умолчанию заблокировано. Нужные соединения разрешаются отдельно.

Например, агент может написать программу для анализа таблицы и выполнить её, не получая заодно доступ ко всей корпоративной сети.

Второй сервис, Akamai Inference, позволяет запускать нейросети через облачную инфраструктуру компании. На старте доступны 12 моделей, включая Google Gemma 4, OpenAI gpt-oss-120b и NVIDIA Nemotron 3 Ultra.

Оба продукта уже доступны в бета-версии. Для Agent Sandbox предусмотрен открытый инструментарий Spin SDK, а доступ к облачному сервису можно запросить у Akamai.
