Новости ИИ

Claude переезжает в облако, Mistral выпускает новую модель, OpenAI ускоряет автоматизацию

Опубликовано: 7 октября 2026

Модели и исследования

С 6 октября новые задачи выполняются на серверах Anthropic; режим «только на компьютере» удалён, вернуться к нему нельзя.

Плюс — фоновые и запланированные задачи продолжаются при выключенном компьютере; минус — данные задачи больше нельзя полностью оставить локально.

Старые локальные сессии не переносятся.

Mistral выпустила Mistral Large 4

Мультимодальная флагманская модель с контекстом 1 млн токенов уже доступна в публичной API-превью за $1,36/$4,18 на миллион входных/выходных токенов.

Открытые веса пока не опубликованы — их обещают до конца октября. Практически это новый относительно недорогой вариант для программирования, агентов, документов и последующего самостоятельного размещения.

OpenAI запустила Decisions API

Публичная бета на gpt-6-luna превращает текст и изображения в классификацию, оценку или выбор из вариантов — заявлено примерно десятикратное ускорение относительно Responses API.

Цена — $0,10 за миллион входных токенов, без оплаты выходных; это инструмент для разработчиков, не функция обычного ChatGPT.

Одновременно уровни API упрощены до Build, Launch и Grow.
