Хакеры взломали OpenAI с помощью Claude. Теперь они её партнёры

OpenAI заключила соглашение с Hacktron — командой, которая ранее обнаружила уязвимости в системе доступа к её внутренним ресурсам. Теперь исследователи будут совместно проверять безопасность интеграций.

OpenAI — Partnering with Hacktron, 6 November 2026 ↗

OpenAI 6 ноября объявила о партнёрстве с Hacktron — командой исследователей, которая летом с помощью нейросети Claude проникла в её системы и получила доступ к аккаунтам сотрудников. Теперь эти же специалисты будут искать уязвимости вместе с инженерами компании.

25 июля исследователи использовали цепочку из двух уязвимостей. Первая находилась в обработке изображений на форуме OpenAI, работавшем на платформе Discourse. Вторая затрагивала механизм единого входа в сервисы компании. Разработать работающий эксплойт помогла модель Claude Opus 5.

Получив доступ к аккаунту сотрудника, исследователи через Codex создали безвредный запрос на изменение файла во внутреннем репозитории OpenAI. Так они продемонстрировали возможность доступа к закрытым разработкам. По собственному отчёту Hacktron, содержимое внутреннего кода команда не изучала.

Исследователи сообщили об уязвимостях, после чего OpenAI и разработчики Discourse выпустили исправления. За находку, связанную с системой авторизации OpenAI, Hacktron получила вознаграждение в $6500.

Теперь компании договорились совместно выбирать наиболее важные направления проверки безопасности. Особое внимание уделят взаимодействию систем OpenAI со сторонними сервисами — именно такие связи позволили исследователям развить июльскую атаку.

Hacktron также получит расширенный доступ к передовым моделям OpenAI через программу Daybreak Red, предназначенную для авторизованных испытаний на проникновение и других сложных исследований безопасности.

Причём партнёров у OpenAI становится больше. Ещё 2 ноября компания пригласила к проверкам исследователей Cathedral, которые ранее проникли во внутренние системы Anthropic. Теперь к ним добавляется команда, обнаружившая серьёзные проблемы уже в самой OpenAI.

Список конкретных систем для новых испытаний и сроки работы Hacktron пока не раскрываются. О результатах совместных проверок компании ещё не сообщали.
