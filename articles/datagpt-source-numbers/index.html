Нейросеть подготовила финансовый отчёт. Цифры красивые, итог сошёлся. А теперь покажите, как вы это считали!

28 октября американская компания Prophecy выпустила DataGPT

— инструмент, который позволяет проверять каждый шаг работы ИИ с корпоративными данными.

Сервис подключается к ChatGPT, Claude и Microsoft Copilot. Он собирает информацию из Excel, SharePoint и корпоративных хранилищ, обрабатывает её и формирует отчёты.

Вместе с результатом пользователь получает наглядную схему всех операций. Можно проверить расчёты, исправить ошибки и утвердить итоговый процесс.

После утверждения DataGPT сохраняет его как обычный программный код. Например, ежемесячный отчёт будет пересчитываться по тем же правилам, без повторного обращения к нейросети.

Сервис уже доступен через поддерживаемые ИИ-платформы и приложение Prophecy. Начать можно бесплатно.
