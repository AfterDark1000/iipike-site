Хакеры с Claude Code взломали не менее 15 медицинских организаций в Аргентине

Опубликовано: 24 октября 2026

У хакеров появилась своя команда. Один ИИ-агент раздаёт задания, второй выполняет. Оба работают на Claude Code. Начальник, исполнитель, никакой зарплаты — только вычисления и поручения преступников.

С помощью такой связки злоумышленники проникли как минимум в 15 медицинских организаций Аргентины. По данным CrowdStrike, по меньшей мере у одной из них похитили пароли и медицинские записи пациентов.

21 октября 2026 года компания опубликовала расследование четырёх хакерских группировок, использовавших ИИ-агентов в реальных атаках с мая по август.

Два агента на грязной работе

Аргентинские медицинские организации атаковал оператор, общавшийся на испанском и английском языках.

Он взял открытый проект PentestGPT, дополнил его инструментами для взлома и построил систему с двумя агентами Claude Code.

Первого назвали Supervisor — руководитель. Он выбирал следующий шаг из заранее предусмотренных этапов атаки. Второй, Executor, исполнял команды.

Цели и общий сценарий задавал человек. А вот разбираться с возникающими препятствиями агенты могли самостоятельно.

В одном из изученных эпизодов первоначальная попытка воспользоваться похищенным паролем провалилась. Система переключилась на другой способ проникновения. Итог — ещё пять украденных паролей.

Для атакующих это удобно: не приходится вручную управлять каждым действием. Для владельцев медицинских баз последствия куда менее приятные.

CrowdStrike не раскрывает названия пострадавших организаций и количество пациентов, чьи данные оказались похищены. Независимых публичных подтверждений от всех жертв пока нет.

Восемьсот девятнадцать навыков. И особого мастерства не требуется

Аргентинская операция оказалась частью гораздо более широкой истории.

Китайскоязычный оператор использовал Claude Code для атак более чем на 20 целей по всему миру. Исследователи установили проникновения в государственные организации двух стран. Среди остальных целей были компании США и Бразилии.

У этого злоумышленника имелось сразу две системы управления агентами. Одна работала по жёсткому сценарию, другая позволяла Claude самостоятельно выполнять задания или распределять их между несколькими специализированными агентами.

Индонезийский оператор обошёлся куда более скромной подготовкой.

Он собрал 819 готовых навыков для Claude Code, преимущественно из открытых репозиториев GitHub, и поручил нейросети искать способы проникновения.

Никакой сложной системы управления агентами. Просто большая коллекция инструментов и надежда, что ИИ сам во всём разберётся.

Иногда Claude упирался в ограничения безопасности или технические препятствия. Тогда хозяину приходилось вмешиваться и подталкивать его к продолжению работы.

Несмотря на довольно кустарный подход, злоумышленник сумел взломать несколько государственных сайтов и коммерческих организаций.

Русскоязычная группировка подготовила для Claude Code сценарий из семи этапов и предоставила агенту почти полную свободу выбора методов атаки.

В результате преступники похитили клиентские данные американского поставщика CRM-систем и проникли в инфраструктуру нескольких других организаций.

Принадлежность операторов к конкретным государствам исследователи не установили. Указанные языки характеризуют их общение, а не гражданство.

Хакеры забыли закрыть собственные двери

Как CrowdStrike удалось разобраться в устройстве всех четырёх операций?

Преступники сами оставили свои системы управления ИИ-агентами в открытых каталогах. Исследователи получили возможность изучить инструменты, настройки и сценарии атак.

Отсюда и вывод CrowdStrike: для успешного применения ИИ в кибератаках уже не обязательно быть выдающимся специалистом. Готовые инструменты и достаточно самостоятельная нейросеть позволяют выполнять работу, которая раньше требовала серьёзной технической подготовки.
