Alibaba выпустила Qwen4-Max: из обучения нейросети убрали инструкции для кибератак

Alibaba выпустила флагманскую Qwen4-Max с дополнительными мерами против злоупотребления моделью для кибератак, архитектурой MoE и миллионным контекстом.

Alibaba Cloud — Alibaba unveils Qwen4-Max (16 November 2026) ↗

Alibaba 16 ноября выпустила Qwen4-Max — новую флагманскую нейросеть, при обучении которой особое внимание уделили кибербезопасности.

Из обучающих материалов отфильтровали инструкции для наступательных кибератак, сохранив знания, необходимые для поиска и исправления уязвимостей.

Alibaba также начала проверять безопасность программного кода прямо во время обучения нейросети. Модель оценивали не только по тому, работает ли написанная программа, но и по наличию опасных ошибок: например, уязвимостей, позволяющих внедрить посторонний код или обойти проверку прав доступа.

Эффективность этих мер против злоупотреблений в реальных условиях пока не получила независимого подтверждения.

2,4 триллиона параметров и дешевле предшественницы

Qwen4-Max построена на архитектуре Mixture-of-Experts: при обработке каждого токена задействуется лишь часть огромной нейросети.

Всего у модели 2,4 триллиона параметров, но на каждый токен приходится около 71 миллиарда активных. Такой подход позволяет использовать большую модель без необходимости задействовать все её параметры одновременно.

Контекстное окно составляет миллион токенов. Нейросеть умеет анализировать изображения и видео, программировать, работать с документами и выполнять длительные задания через подключённые инструменты.

В тесте Alibaba Work360, охватывающем профессиональные задачи из 721 области, Qwen4-Max превзошла предыдущую Qwen3.8-Max. При высоком уровне рассуждений новая модель расходовала на 35% меньше токенов, а средняя стоимость выполнения заданий снизилась примерно на 60%.

Компания также сообщила о шестом месте Qwen4-Max в рейтинге Code Arena, где оценивают программирование.

В одной из промышленных демонстраций Alibaba время программирования обработки детали сократилось с 475 до 24 минут.

Что стало с предварительной версией

Всего пять дней назад Alibaba открыла доступ к Qwen4-Max-Preview и сразу объявила дату её отключения. Предварительную модель разрешили тестировать с 11 по 25 ноября.

Теперь появилась полноценная Qwen4-Max. Её можно использовать через QwenCloud API, а также в сервисах QwenWork и QwenStudio.

Флагманская модель распространяется через облачные сервисы. Позднее Alibaba планирует выпустить модели семейства Qwen4 меньшего размера с открытыми весами для самостоятельного запуска и доработки.
