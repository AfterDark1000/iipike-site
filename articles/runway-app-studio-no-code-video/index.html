Runway научила ИИ создавать видеогенераторы без кода!

Опубликовано: 28 октября 2026

Генерация видео
Компании и продуктыRunway

26 октября Runway запустила App Studio, конструктор собственных ИИ-приложений без программирования.

Пользователь объясняет, что должно делать приложение, а Runway создаёт интерфейс, пишет код, подключает нужные модели и запускает готовый инструмент.

Например, можно собрать программу, которая превращает фотографию здания в видеопролёт по заданной траектории камеры. Или сервис, который заменяет персонажа в ролике, сохраняя движения и композицию сцены.

Самое интересное — возможность превратить уже настроенный рабочий процесс в приложение одним нажатием.

Допустим, вы долго подбирали модели, референсы и промпты, чтобы получать ролики в определённом стиле. App Studio сохранит эту последовательность, добавит удобные поля для ввода данных и позволит запускать её снова без ручной настройки каждого этапа.

Готовое приложение можно оставить себе, передать коллегам или опубликовать по ссылке. Для использования потребуется аккаунт Runway, а генерации будут оплачиваться кредитами самого пользователя.

В App Studio уже есть готовые примеры: замена персонажей, монтаж рекламных кадров, точное редактирование изображений и управление виртуальной 3D-камерой.

Создавать собственные приложения могут все пользователи платных тарифов Runway.
