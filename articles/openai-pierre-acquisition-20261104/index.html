OpenAI покупает Pierre: её инструменты уже работают в Codex

OpenAI объявила о намерении приобрести Pierre Computer Company, чьи библиотеки Trees и Diffs уже используются в Codex. После сделки компания планирует интеграцию Code Storage.

Опубликовано: 6 ноября 2026

Первоисточник

OpenAI — OpenAI to acquire Pierre Computer Company, 4 ноября 2026 ↗

OpenAI 4 ноября объявила о намерении приобрести Pierre Computer Company — разработчика инструментов для работы с программным кодом. Причём две библиотеки Pierre уже встроены в Codex: разработчики используют их при просмотре файлов и проверке изменений, сделанных в том числе ИИ-агентами.

Речь об инструментах Trees и Diffs. Первый помогает быстро ориентироваться в структуре проекта, второй показывает, какие строки кода изменились. Причём Diffs позволяет исправить ошибку прямо в окне сравнения версий.

У Pierre есть и другие разработки. Highlights подсвечивает синтаксис программного кода в реальном времени — даже когда ИИ-агент генерирует его на лету.

Отдельный продукт компании — Code Storage, сервис для хранения кода и истории его изменений на основе Git. OpenAI собирается перенести его возможности в Codex после завершения сделки.

Сначала Pando, теперь Pierre

Всего двумя днями ранее OpenAI рассказала о Pando — собственной серверной системе для Git. Её пришлось создавать из-за резко выросшей нагрузки: ИИ-агенты стали выполнять множество задач одновременно, а прежняя инфраструктура перестала справляться с потоком изменений.

По темеCodex так разогнал разработку, что OpenAI пришлось создавать новый Git-серверНовости ИИ · 3 ноября 2026

Pando решает проблему обработки большого числа операций с кодом. Инструменты Pierre помогают разработчикам работать с результатами: просматривать файлы, разбираться в изменениях, исправлять ошибки и управлять историей проекта.

OpenAI хочет собрать эти возможности непосредственно в Codex, чтобы разработчики и ИИ-агенты могли работать над программами в единой среде.

Компания обещает сохранить открытый исходный код библиотек Pierre и продолжать их развитие. Действующие клиенты Code Storage смогут пользоваться сервисом и после закрытия сделки, пока его функции переносят в Codex.

Сумму покупки и предполагаемую дату завершения OpenAI не раскрыла. Сделка требует необходимых согласований, включая разрешения регулирующих органов. До её закрытия компании продолжат работать независимо.
