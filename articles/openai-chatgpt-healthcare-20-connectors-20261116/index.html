ChatGPT разобрал многомесячный завал документов в больнице за выходные

В CVS Health ИИ-агент за выходные разобрал многомесячную очередь документов. OpenAI представила более 20 медицинских подключений ChatGPT for Healthcare и работу агентов с больничными программами.

В американской сети CVS Health ИИ за одни выходные разобрал очередь документов, скопившуюся за несколько месяцев.

OpenAI 16 ноября представила обновление ChatGPT for Healthcare. В систему добавили более 20 медицинских подключений и возможность поручать ИИ-агентам работу в больничных программах.

Агент самостоятельно перемещается между приложениями, читает информацию с экрана, нажимает кнопки и заполняет формы.

Например, врач назначает пациенту МРТ. Для обследования требуется согласование со страховой компанией. ИИ изучает историю болезни, предыдущие снимки и назначения, затем готовит документы для врача и заявку страховщику.

Всё это OpenAI показала на демонстрации с вымышленным пациентом.

А вот CVS Health уже использует таких агентов в рабочих процессах. Один из них за выходные разобрал многомесячную очередь отправки документов. Другой ежедневно выполняет технические операции для десятков тысяч консультаций специалистов.

Компания Cigna Healthcare тоже применяет ИИ для сбора информации о пациентах. Раньше её сотрудникам приходилось искать нужные сведения более чем в десяти разных медицинских и административных системах. Теперь агент собирает их за секунды.

Что подключили к ChatGPT

Более 20 новых медицинских плагинов позволяют работать с привычными больничными сервисами прямо в разговоре с нейросетью.

Среди них Metriport для поиска медицинских записей, UpToDate для получения клинических рекомендаций, Amion для поиска дежурных специалистов и Turquoise Health для сравнения стоимости процедур.

В одном из примеров врач запрашивает выписку пациента после госпитализации, проверяет изменения в назначенных лекарствах и получает рекомендации по дальнейшему наблюдению.

Похожую задачу автоматизации медицинской документации решает и Google, которая ранее представила Gemini для работы с больничными картами и страховками.

По темеGoogle представила Gemini для больниц: ИИ разберёт медкарты и страховкиНовости ИИ · 12 ноября 2026

OpenAI также обновила поиск медицинских исследований. В проверке с участием врачей провели более 1300 оценок ответов ChatGPT. Обновлённая система получила более высокие оценки по всем восьми проверявшимся критериям, включая точность и безопасность.

Решения, требующие медицинской квалификации, остаются за врачами. Организации могут ограничивать действия агентов, требовать согласования отдельных операций и сохранять историю работы.

Новые подключения уже доступны организациям с ChatGPT for Healthcare. Часть инструментов доступна американским врачам через ChatGPT for Clinicians. Для разработчиков предусмотрен доступ через API OpenAI.
