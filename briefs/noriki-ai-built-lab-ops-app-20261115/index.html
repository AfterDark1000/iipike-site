Учёный собрал с помощью ИИ замену Slack и таблицам для своей лаборатории

19 ноября 2026 · 23:08

Исследователь, публикующийся под именем Noriki, показал собственное приложение для управления лабораторией. По его словам, он написал его при помощи Claude Code и Codex, собрав в одном месте рабочий чат, календарь, права доступа, учёт оборудования и закупки. Раньше для этих задач команда использовала Slack и электронные таблицы. О работе системы известно по демонстрации самого автора.
