Kong запустила облако, где ИИ ищет ошибки и предлагает исправления

21 ноября 2026 · 17:08

Компания Kong 19 ноября представила Volcano — облачную платформу для запуска ИИ-агентов и приложений. Встроенный инструмент LavaFlow, по заявлению разработчиков, разбирает повторяющиеся сбои по журналам и исходному коду, после чего предлагает исправление через запрос на изменение в GitHub. По умолчанию такой код должен проверить и принять человек; автоматическое объединение исправлений настраивается отдельно.
