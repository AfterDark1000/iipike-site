Novita признала, что запросы к MiniMax могли попасть к третьей стороне

23 ноября 2026 · 19:47

Novita сообщила об ошибке маршрутизации: часть запросов к MiniMax проходила через официальный API разработчика модели вместо серверов Novita. Риск касается обращений с 28 мая по 11 ноября 2026 года, в том числе переданных через OpenRouter. Содержание запросов могло быть доступно сторонней компании или сохранено ею; масштаб такого доступа ещё выясняют. Затронутые модели отключены. Пользователям, отправлявшим в запросах пароли или API-ключи, советуют их заменить.
