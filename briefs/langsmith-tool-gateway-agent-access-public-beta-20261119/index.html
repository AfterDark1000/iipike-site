LangChain запустила «пропускной пункт» для инструментов ИИ-агентов

21 ноября 2026 · 15:53

LangChain выпустила в публичную бету LangSmith Tool Gateway — единый шлюз для инструментов, которыми пользуются ИИ-агенты. Через него можно разрешать каждому агенту только нужные действия, назначать учётные данные и просматривать журнал обращений. Разработчикам достаточно подключить один адрес вместо отдельной настройки каждого инструмента. Шлюз работает с MCP и клиентами вроде Claude Code и Cursor.
