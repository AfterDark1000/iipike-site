Поиск для ИИ-агентов AWS научился учитывать страну и новые языки

23 ноября 2026 · 21:09

Amazon обновила Web Search в Bedrock — инструмент, которым ИИ-агенты ищут свежую информацию в интернете. Разработчик теперь может указать двухбуквенный код страны, например JP или DE, и поиск отдаст приоритет источникам из неё. Добавлена поддержка запросов на испанском, французском, немецком, итальянском и японском, а также региональных вариантов английского. Обновление доступно с 21 ноября в поддерживаемых регионах AWS Bedrock и AgentCore.
