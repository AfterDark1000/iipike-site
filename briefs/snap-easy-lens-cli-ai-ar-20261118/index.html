Snapchat разрешил Claude Code и Codex создавать AR-маски по описанию

20 ноября 2026 · 13:38

Snap 18 ноября выпустила Easy Lens CLI — бесплатный инструмент, который подключает Claude Code, Codex и Cursor к созданию масок и дополненной реальности для Snapchat. Разработчик описывает эффект обычным языком, а ИИ собирает его из готовых блоков, создаёт материалы и помогает проверить результат на телефоне. Через тот же инструмент маску можно отправить на публикацию. CLI доступен на Windows, macOS и Linux с аккаунтом Snapchat.
