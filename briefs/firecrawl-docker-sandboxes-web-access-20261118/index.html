Firecrawl дала ИИ-агентам доступ к сайтам без передачи ключа в песочницу

20 ноября 2026 · 09:08

Firecrawl выпустила комплект интеграции с Docker Sandboxes для ИИ-агентов Claude Code и Codex. Агент работает в изолированной среде и может искать и читать сайты через разрешённый адрес Firecrawl, не получая прямой доступ ко всему интернету. API-ключ хранится на стороне компьютера-хоста, а не внутри песочницы. Комплект доступен, но технология Docker Kits пока находится в раннем доступе и может измениться.

Первоисточник: Firecrawl ↗
