Mistral выпустила Vibe Desktop — ИИ-агента для работы с файлами и кодом

20 ноября 2026 · 13:53

Mistral 17 ноября выпустила Vibe Desktop для Windows и macOS. В одном приложении собрали работу с локальными файлами, программирование и облачные задачи ИИ-агентов. Пользователь может поручить агенту изменения в проекте, следить за командами и проверять правки кода, не переключаясь между окнами. Vibe поддерживает параллельные задания и работу с Git-репозиториями. Версия для Linux пока только запланирована.

Первоисточник: Mistral AI ↗
