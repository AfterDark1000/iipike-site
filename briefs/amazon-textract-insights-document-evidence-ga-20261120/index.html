Amazon научила ИИ извлекать данные из документов со ссылкой на страницу

23 ноября 2026 · 18:39

Amazon выпустила Textract Insights для разбора больших пакетов документов. Пользователь описывает нужные поля обычными словами, а сервис сам разделяет сканы на документы, распознаёт их тип и возвращает найденные значения. Для каждого ответа он указывает страницу-источник и оценку уверенности, чтобы сомнительные результаты можно было перепроверить. Через API функция доступна в двух регионах AWS в США: Северная Вирджиния и Орегон.
