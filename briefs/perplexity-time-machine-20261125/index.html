Perplexity запустила машину времени для интернет-поиска

26 ноября 2026 · 20:39

Perplexity представила Time Machine, позволяющую искать информацию в интернете такой, какой она была на выбранную дату за последние 365 дней. Система использует сохранённые копии веб-страниц. Можно, например, узнать, сколько стоила подписка на какой-либо сервис несколько месяцев назад или как изменились условия его использования. Функция доступна разработчикам через API без дополнительной наценки.
