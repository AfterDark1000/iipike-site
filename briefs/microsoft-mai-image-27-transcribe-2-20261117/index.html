Microsoft выпустила ИИ для редактирования картинок и расшифровки речи

20 ноября 2026 · 09:38

На конференции Ignite 17 ноября Microsoft представила MAI Image 2.7 и MAI Transcribe 2. Первая модель редактирует изображения и, по данным компании, заняла первое место в рейтинге Artificial Analysis по качеству правок; облегчённая Flash рассчитана на массовую генерацию. Вторая предназначена для распознавания многоязычной речи и уже используется в медицинском Dragon Copilot. Image 2.7 доступна в предварительной версии через Microsoft Foundry.

Первоисточник: Microsoft AI ↗
