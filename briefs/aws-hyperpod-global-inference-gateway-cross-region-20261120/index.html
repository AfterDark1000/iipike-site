AWS научила ИИ-кластеры подхватывать нагрузку друг у друга

23 ноября 2026 · 12:39

AWS представила Global Inference Gateway для SageMaker HyperPod. Шлюз принимает запросы к ИИ-моделям через единый адрес и распределяет их между вычислительными кластерами, даже если они находятся в разных регионах. Когда один кластер перегружен или выходит из строя, запросы можно автоматически направить на другой. Сервис рассчитан на команды, запускающие модели в кластерах HyperPod, и доступен в 13 регионах AWS.
