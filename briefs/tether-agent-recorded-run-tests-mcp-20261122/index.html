Tether позволяет проверять ошибки ИИ-агентов без повторной оплаты модели

24 ноября 2026 · 10:09

В открытом инструменте Tether 0.4.0 появилась автоматическая проверка записанных сеансов ИИ-агентов. Можно выяснить, какие программы вызывал агент, что он записал в файлы и уложился ли в заданный бюджет. Для воспроизведения старого сеанса новые запросы к модели не нужны. Уже 22 ноября вышла версия 0.5.0 с поддержкой внешних инструментов через MCP.
