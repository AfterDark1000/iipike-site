SK hynix показала серверную стойку MARS, которая делит память между ИИ-машинами

23 ноября 2026 · 13:24

На выставке Supercomputing 2026 компания SK hynix показала три демонстрации MARS — стойки для ИИ-серверов с общей системой памяти. Один сценарий позволял нескольким машинам повторно использовать уже рассчитанные данные модели (KV-кэш), не гоняя их заново через сеть. В другом через общую память обменивались подготовленными для модели токенами, уменьшая простои ускорителей. Пока компания рассказывает об испытаниях и демонстрациях; сроки коммерческого выпуска MARS не названы.
