Amazon Polly научилась клонировать голоса по нескольким минутам записи

20 ноября 2026 · 19:08

Amazon добавила в Polly создание синтетического голоса по нескольким минутам записи человека, который дал на это согласие. Такой голос затем может озвучивать новый текст. Поддерживаются семь языков, включая английский, испанский и немецкий; русского среди них нет. AWS пока открыла функцию избранным клиентам, остальные могут подать заявку. На созданное аудио Amazon наносит цифровой водяной знак, а доступ к голосу ограничен аккаунтом владельца.

Первоисточник: Amazon Web Services ↗
