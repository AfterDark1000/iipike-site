Стэнфорд упаковал историю 107 бесед в 16 токенов памяти

19 ноября 2026 · 20:08

Исследователи Стэнфорда представили Memorilla — систему памяти для языковых моделей, которая извлекает нужные для ответа сведения из длинной истории документов и переписок в небольшое число специальных токенов. В одном из тестов история из 107 разговоров объёмом около 32 тысяч токенов представлялась для модели всего 16 токенами памяти. Авторы опубликовали код и обученные компоненты, а результаты пока получены в исследовательских испытаниях.

Первоисточник: Stanford SNAP / Memorilla ↗
