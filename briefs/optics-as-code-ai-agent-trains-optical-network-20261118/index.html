ИИ-агент научился настраивать нейросеть из света по снимкам камеры

21 ноября 2026 · 14:53

Исследователи показали, как ИИ-агент обучает настоящую оптическую нейросеть без заранее откалиброванной цифровой модели оборудования. Агент пишет код, меняет настройки световых элементов и по снимкам камеры оценивает результат. В экспериментах с распознаванием и кодированием изображений метод обошёл обычные способы настройки без вычисления градиентов. Пока это результат научной работы, опубликованной 18 ноября.

Первоисточник: arXiv, исследователи Стэнфордского университета и коллеги ↗
