Cloudflare позволяет открыть поиск по сайту для нейросетей одной кнопкой

26 ноября 2026 · 18:24

Cloudflare представила Search for Agents. Владельцы сайтов могут включить специальный поиск для ИИ-агентов прямо в панели управления. Сервис самостоятельно индексирует содержимое сайта, позволяя нейросетям находить нужную информацию без перебора отдельных страниц. Функция доступна даже на бесплатном тарифе с установленными лимитами.

Первоисточник: Cloudflare ↗
