# Каталог компаний и продуктов ХПИИ

Публичный раздел: /entities/. Генератор: scripts/site_entities.py. Источник привязок:
data/entity_registry.json — редакционно проверенный список ID уже опубликованных новостей.

- Раздел использует **статические HTML**, существующий news.json и локальные SVG.
- Одно событие может относиться сразу к двум компаниям и продукту.
- **Автоматический поиск по полному тексту отключён**: случайные упоминания не создают тег.
- Сейчас справочник содержит **ручную выборку**, а не весь архив. Новые статьи не
  получают компанию/продукт без отдельного редакционного решения.
- Любая новая компания или продукт добавляется в JSON по разрешённому ключу
  после проверки принадлежности новости и ссылки на существующий ID. Для продукта
  обязательно существующая компания-владелец.
- Для обновления: \`python3 -m scripts.site_entities\`, затем
  \`python3 scripts/build_sitemap.py\`, проверки \`--check\` и полноценные CI-тесты.
- Изменение одного лишь текста статьи или пересказа новости **не меняет** таксономию.

Это первая публичная стадия. Автоматическую передачу **явно выбранных** меток
из редакционного входящего JSON в news.json добавлять только после
отдельной проверки протокола публикации и точных регрессий. Не включать
эвристическое «распознавание всех упоминаний» в новостном конвейере.

Изображения брендов перенесены из \`lab/entities/icons/\`, атрибуция и MIT
сохранены в \`lab/entities/ICONS.md\` и \`lab/entities/ICONS-LICENSE.txt\`.
