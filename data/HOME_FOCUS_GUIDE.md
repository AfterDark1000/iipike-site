# ХПИИ — «В фокусе» на главной

Файл управления: [data/home_focus.json](../data/home_focus.json). На главной это **первый редакционный блок после шапки и рубрик**, перед лентой собственных публикаций. Дзен-лента перенесена ниже всех собственных материалов и лаборатории.

- Можно закрепить **не более трёх** материалов с уже существующими опубликованными страницами сайта. Внешние ссылки и черновики не допускаются.
- Порядок элементов задаётся порядком объектов в массиве items: **первая** карточка крупная, две остальные вспомогательные.
- kind="editor" — закрепление до явной редакторской команды «открепить»; без expires_at.
- kind="hot" — горячая новость, можно задать expires_at в часовом поясе Усть-Катава (+05:00). В браузере карточка исчезнет после срока, даже если GitHub Pages не пересобирался. После следующей сборки тоже требуется актуализировать список: JS скрывает истёкшую карточку без ошибки и переназначает размер сетки.
- label — короткая редакционная метка, например «Горячая тема», «Разбираемся», «Выбор редакции».
- Попытка указать некорректный ID, дубликат, больше трёх записей или неверную дату блокируется при сборке.
- **Срочная публикация ≠ автоматическое закрепление:** только отдельное указание пользователя может добавить новость в «В фокусе».
- Изменения в JSON нужно сопровождать обновлением главной: `python3 scripts/build_home_published.py`. CI проверяет `--check` и регрессионные тесты. Сайт продолжает публиковать статьи из очереди автоматически, меняя только последнее в своём блоке.
- Убрать раздел целиком: поставить `"items": []`, пересобрать главную. Навигационную ссылку `#focus` при полном удалении также надо заменить на `#archive`.
