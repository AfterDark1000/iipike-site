# Хроники Пикирующего ИИ — пилотный сайт

Публичный статический сайт на GitHub Pages: https://afterdark1000.github.io/iipike-site/

Внутри — первый проверенный тестовый материал, архив, RSS, карта сайта и исходные тексты в JSON. Для размещения: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Это первая тестовая сборка. **Автоматического написания и публикации новостей пока нет.** Сейчас это статический сайт.

Исходная иллюстрация в ZIP-пилоте была растровая; в первой загрузке в репозиторий используется векторная версия обложки (SVG), чтобы сайт не зависел от недоступной для коннектора передачи бинарного изображения. Позже можно заменить на полную растровую версию.
