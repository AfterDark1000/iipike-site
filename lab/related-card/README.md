# ХПИИ — лаборатория карточек перелинковки

Это два **неиндексируемых визуальных прототипа**. Боевой HTML-сборщик уже умеет создавать одну карточку внутри статьи (см. `scripts/site_related_cards.py`), но макеты здесь изолированы от реальных публикаций.

- `/lab/related-card/` — карточка в теле статьи, вслед за абзацем с контекстом (дизайн для точной внутренней связи).
- `/lab/related-card/fallback/` — тот же реальный материал без редакторских ссылок, карточка другой опубликованной статьи размещена после основного текста.
- Оба адреса не включены в `news.json`, Sitemap или RSS, помечены `noindex,nofollow,noarchive`, без canonical и NewsArticle-структурированных данных.
- Стили прописаны только в тестовых HTML-файлах и не меняют действующие статьи.
- Демонстрация основана на статье Алекса Стамоса; реальная тема карточки — расследование Censys об ARTEX. Оригинал статьи остаётся нетронутым.

## Рабочие правила для сайта

1. **Есть проверенная внутренняя ссылка:** редакторская связь имеет приоритет. Одну проверенную ссылку на существующую страницу сайта превращать в компактную карточку после абзаца и оставлять слова вместо ссылки. В утверждённом Markdown для Дзена исходная ссылка не меняется. Не дублировать этот переход в блоке «Читайте также».
2. **Редактор вообще не выбирал перелинковку:** возможно подобрать *не более одной* ранее опубликованной статьи по редкому конкретному имени проекта/продукта и общей теме. Имя должно относиться к главному предмету статьи (заголовок/аннотация) или подтверждаться несколькими смысловыми абзацами. Одиночная сравнительная ремарка не годится. Если есть даже Дзен-ссылка без опубликованного аналога на сайте или `related_dzen_ids`, не заменять выбор редактора сторонней автокарточкой.
3. Если нет убедительного совпадения, **карточки нет**. Не выдавать похожую по ключевым словам новость за прямое продолжение события.
4. Не предлагать собственную статью, непубличный материал, Дзен вместо существующей страницы iipike.ru, и не повторять тот же адрес в блоке «Читайте также».
5. Сохранить `article_markdown` для Дзена дословно. Любая карточка — элемент рендеринга HTML, а не переписывание одобренного текста.
6. В боевом режиме карточка появляется **после подходящего смыслового абзаца**. Макет `/fallback/` служит только для сравнения, его размещение в конце не используется в продакшен.

## Аудит 10 ноября 2026 года

Проверено 52 сайта-первичных выпуска (3–10 ноября): 27 HTML-страниц с карточками; из них 3 созданы резервным подбором без ссылок редактора. Выявлены слишком широкие автосовпадения на единичном сравнении (учёба OpenAI → Pierre/Codex; сравнения с DeepSeek) и риск замены неперенесённой в сайт редакторской ссылки на случайный материал. После аудита критерии автоподбора ужесточены **только в сборщике**. Уже сгенерированные HTML без новой штатной пересборки не изменяются.

## Как убрать тест

После решения удалить целиком `lab/related-card/` из репозитория и соответствующие тестовые утверждения в `tests/test_search_indexing.py`. Индексы и реальные статьи от этого не изменятся.
