Дзен · локальная диагностика A.2 для Windows

1. Распакуйте весь архив в папку, например в «Документы».
2. Если Python ещё не установлен, установите Python 3.11 или новее с
   https://www.python.org/downloads/windows/ .
   В установщике отметьте «Add Python to PATH» и оставьте Tcl/Tk включённым.
3. Дважды щёлкните Start-Dzen-A2.cmd. В первый раз пакет установит
   Playwright в эту папку. Нужен установленный Chrome или Microsoft Edge.
4. Нажмите «Проверить доступность». Не вводите данные в окно браузера.
   Когда проверка завершится, отправьте файл dzen-a2-report.json из этой папки.

Ручное сравнение необязательно. Если вы открывали проверяемую ссылку в
обычном браузере, можно отметить результат рядом с названием канала.
Пакет обновит сохранённый отчёт после изменения отметки.

Программа отправляет только ограниченный набор запросов к контрольным адресам.
В отчёт попадают видимые поля статьи и статусы проверки. Файл сохраняется
на вашем компьютере. Сеанс из обычного браузера программе не требуется.
