# Значки для экспериментального каталога

Иконки Google, OpenAI, Adobe, xAI, Anthropic, Grok, Gemini, Claude и Firefly — [Lobe Icons](https://github.com/lobehub/lobe-icons), набор `packages/static-svg/icons`, MIT, © 2023 LobeHub. Некоторые монохромные SVG адаптированы для контрастности на светлом фоне, без изменения формы. ChatGPT использует знак OpenAI с другим цветом. Для Disney — оригинальная буквенная эмблема, не официальный логотип.

SVG-файлы хранятся локально; браузер не загружает изображения со сторонних серверов. Логотипы и названия брендов принадлежат их правообладателям и используются в информационных целях. Лицензия включена в `ICONS-LICENSE.txt`.
