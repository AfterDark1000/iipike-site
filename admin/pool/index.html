Очередь сырья

Пул — ещё не очередь публикаций. «Согласована» означает завершение работы с исходной новостью, а не выход статьи на сайте. Решения сортировщика показываются отдельно от статуса обработки.

Читаю данные…
Данные только для просмотра, прямо из публичного GitHub. Кнопки и фильтры ничего не меняют в пуле. Время обновления — время загрузки в этот браузер.
