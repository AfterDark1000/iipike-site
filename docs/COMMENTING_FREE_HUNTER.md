# ХПИИ — Дзен-охотник (бесплатный автономный пилот)

**Задача:** система САМА находит **прямые** ссылки на публикации Дзена для ручного комментинга. Не требуется читать каналы или собирать ссылки вручную. Никаких платных API. Пилот не трогает существующий генератор комментариев Gemini.

## Как работает

1. GitHub Actions раз в 4 часа выполняет Python-скрипт на бесплатном GitHub runner (при доступности лимитов аккаунта).
2. Скрипт проверяет RSS-поиск Google News, Bing News и Bing Web по 8 темам — он сам делает поисковые запросы в RSS и получает результаты. Это не штатный поиск Дзена.
3. Дополнительно можно подключить **Google Alerts RSS**: один раз создаются поисковые оповещения вида `site:dzen.ru/a/ (ChatGPT OR нейросеть)` с доставкой **RSS**. Затем они обновляются автоматически и могут находить независимых авторов, не только СМИ. RSS-адреса хранятся в GitHub secret `GOOGLE_ALERTS_FEEDS`, по одному в строке; не добавлять в исходники.
4. Сборщик извлекает только реальные адреса публикаций `https://dzen.ru/a/...`, `https://dzen.ru/b/...` или допустимые старые `/media/...`. Любые `/search`, страницы каналов, URL изданий и нераспознанные ссылки отбрасываются.
5. Проверяет наличие ИИ-тематики и дату появления результата в RSS за последние 72 часа, если RSS её предоставил; веб-результаты Bing без даты отправляются отдельно как недатированные кандидаты, убирает дубли, сохраняет результаты в отдельной ветке `commenting-free-data`, не меняя основную очередь публикаций.
6. Отдельная страница `/admin/commenting/hunter/` выводит найденные прямые ссылки, позволяет искать в результатах и отмечать «разместил/пропустил».

**Важно:** дата записи в RSS может обозначать дату индексации, а не публикации в Дзене. Статья может быть старой! Ссылки в ленте обозначены «не проверено открытием», поскольку бот к Дзена напрямую НЕ обращается. Это осознанное ограничение, а не подтверждение свежести. Если поисковые RSS не покрывают небольшие каналы — будет мало результатов или ноль, даже если в Дзене материалов много. В отчёте это честно видно.

## После принятия PR

- Только после merge в `main` GitHub начнёт плановые прогоны с периодичностью 4 часа. Этот PR оставлен черновиком на время проверки.
- Чтобы проверить один раз: в Actions выбрать **HPII - Free Dzen direct-link hunter** → **Run workflow** (после merge), затем зайти на `/admin/commenting/hunter/`.
- Для расширения охвата настроить 3–8 Google Alerts. Инструкция: https://www.google.com/alerts → запрос, Show options → Deliver to: RSS feed → Create Alert → скопировать адрес RSS по иконке. В настройках репозитория GitHub Secret `GOOGLE_ALERTS_FEEDS` — каждый адрес с новой строки. Ссылки на свои RSS держать в секрете (они идентифицируют оповещения).
- Никаких покупок, регистрации у платного провайдера, установки расширения или ручного посещения каналов для сбора ссылок не требуется.

## Границы первого пилота

- **НЕ** запускается автоматический скрапинг dzen.ru, поиск `/search`, вход в аккаунт, обход капчи, работа с прокси или публикация комментариев.
- **НЕ** подтверждается полнота индексации, просмотры или количество подписчиков. Поиск небольших каналов есть, **доказательств качества охвата пока нет**.
- **НЕ** предполагается, что Google News RSS всегда содержит прямые ссылки: некоторые результаты ведут через агрегатор Google, и такие ссылки будут пропущены; Google Alerts RSS полезнее для поиска самостоятельных авторов.
- Текущий `/admin/commenting/` и Gemini не затронуты. Сначала проверить минимум несколько десятков реальных найденных ссылок; только затем подключать к очереди.

## Локальные тесты

Нужен Python 3.11+ без сторонних пакетов:

    python3 -m unittest discover -s tests -p 'test_commenting_free_hunter.py' -v
    python3 scripts/commenting_free_hunter.py --output hunter_queue.json

На машинах без сети скрипт выведет диагностические ошибки и пустой список, а не выдуманные результаты. GitHub Actions проверит сетевую доступность только после включения.

## Следующий этап при слабом охвате

Добавить наблюдение за найденными каналами через независимые публичные ленты/разрешённые источники, чтобы один раз обнаруженного маленького автора не потерять. Это потребует измерений реальной отдачи, а не ещё одного абстрактного «парсера». Приоритет — прямые ссылки и живое обсуждение.

### Поиск без дат

Bing Web RSS позволяет искать весь веб, включая обычные авторские страницы Дзена, и может вернуть ссылку без даты. Такие ссылки показываются только с пометкой «дата неизвестна», их нельзя считать свежими статьями. Без даты статьи только новые для нашей базы, а не доказанно новые в Дзене.
