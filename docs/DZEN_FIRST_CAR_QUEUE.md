**Частота пригодных окон неизвестна.** При непрерывном покрытии известного периода частота будет равна числу ИИ-статей за этот период и числу статей, обнаруженных в первые 60 минут при 0–3 комментариях, пересчитанным на неделю. Покрытие этих двух величин необходимо указать отдельно. Для статуса `confirmed_candidate` нужны подтверждённая тематика и повторяемые обсуждения на сравнимой по возрасту истории со сверенными просмотрами. `low_priority` применим при достаточной истории с результатом ниже пилотных ориентиров. При недостатке наблюдений или зрелых статей остаётся `insufficient_evidence`.

## Локальный прототип

Откройте `lab/dzen-first-car/index.html` из этой ветки. Файлы CSS и JavaScript должны оставаться рядом. Сервер и доступ к сети для запуска не нужны. [Файлы прототипа](../lab/dzen-first-car/)

Если браузер блокирует локальные HTML-файлы, можно открыть `http://127.0.0.1:8000/` после запуска из корня ветки:

```console
python -m http.server 8000 --bind 127.0.0.1 --directory lab/dzen-first-car
```

- Во вкладке **Очередь** видна пустая выдача и причина, по которой снимки шести каналов не дали готовых карточек.
- Во вкладке **Каналы** неизвестные значения обозначены явно. Медиана Guru подписана отдельно. Для двух каналов показано число архивных совпадений и записей с комментариями.
- Во вкладке **Демо · архив** две реальные ИИ-статьи из прежних снимков показывают прямую ссылку, время, возраст при обнаружении, комментарии и историю канала. У обеих в своих снимках наблюдалось по 0 комментариев. Карточки старше пилотного окна, источник помечен как устаревший. Эти статьи относятся к другим каналам и служат только для демонстрации. [Снимки с исходными значениями](DZEN_DISCOVERY_STAGE_A4_2026-11-18.json)

**Открыть** ведёт по прямой ссылке в новой вкладке. **Прокомментировано** и **Пропустить** ставят локальные отметки, которые можно снять кнопкой **Вернуть**. Демо и очередь хранят отметки раздельно. В рабочую очередь попадают только подтверждённые ИИ-статьи подтверждённых каналов с точным временем, открытыми комментариями и известным счётчиком 0–3. Просмотры новой статьи отображаются справочно. Для прототипа выбран срок актуальности снимка 15 минут. Возраст и актуальность проверяются при открытии и возврате к вкладке.

## Что нужно для регулярного источника

Допуск к регулярному чтению и хранению данных из внутреннего `/api/v3/launcher/export` пока не установлен. HTTP 200 и правила для роботов описывают техническую доступность. §5.3.1 условий Дзена отдельно оговаривает назначение пользовательских данных и дальнейшее распространение, §6.2–6.3 ограничивают использование и обход ограничений. В этой проверке внутренний интерфейс Дзена не использовался. [Условия Дзена](https://dzen.ru/legal/ru/termsofuse/index.html) · [Предыдущая проверка](DZEN_DISCOVERY_STAGE_A5.md)

Практические варианты для небольшого согласованного пилота:

1. **Авторские данные.** Сотрудничающий издатель предоставляет разрешённую выгрузку из своей Студии и прямые ссылки Дзена. До подключения сверяются точное время публикации, комментарии по каждой статье и показатели на одном возрасте. Выгрузка годится для подтверждения истории. Для окна 30–60 минут от издателя нужен отдельно согласованный способ своевременной передачи метаданных. [Официальный обзор Студии](https://object2-ac.vk-apps.com/vk-education-0554ff56-27eb-4093-a702-685722cef6d9/media/6c/576cd216b19546e79ec138a791705499.pdf) · [Статистика публикаций от команды Дзена](https://t.me/s/zenforcreators/1527)
2. **Разрешённая интеграция или поставщик.** Зафиксировать у Дзена или поставщика разрешённый способ получения и хранения данных, лимиты, задержку и доступные поля. Коммерческие сервисы описывают аналитику отдельных материалов, но бесплатный программный доступ с нужной частотой не подтверждён. Перед пилотом нужны сверка одних и тех же URL и фактическая задержка. [Описание аналитики Zenstat](https://zenstat.ru/stat/channels/) · [Документация выгрузки Dzen Guru](https://dzen.guru/docs/analitika-i-nishi/vygruzka-statey)

Для пользователя действие остаётся ручным: открыть статью, оставить комментарий в Дзене и при желании поставить локальную отметку. Прототип изолирован от рабочей админки.
