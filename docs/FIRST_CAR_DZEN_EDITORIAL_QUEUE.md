## Постоянный адрес

После утверждения и публикации этой ветки страница будет открываться по адресу [iipike.ru/admin/first-car/](https://iipike.ru/admin/first-car/). В главную админку добавлена ссылка. Страница использует существующий GitHub-вход и вызывает источники после успешной проверки сессии. Это та же клиентская схема авторизации, что в остальных разделах на GitHub Pages. Публичный JSON и статические файлы сохраняют свой текущий режим доступа. Отметки локальные и не синхронизируются с комментингом админки.

Страница читает действующий JSON Gemini и показывает реплики младше 24 часов. При отсутствии прямого URL доступен ручной поиск. Разовые наблюдения Дзена хранятся в маленьком списке и автоматически исчезают из очереди через 24 часа от публикации. При повторном открытии браузер сам не запрашивает Дзен. Пять каналов остаются доступны для ручного просмотра. Автономный регулярный источник свежих статей сторонних авторов пока не подтверждён. [Рабочий JSON Gemini](https://raw.githubusercontent.com/AfterDark1000/iipike-site/commenting-data/commenting/queue.json)
