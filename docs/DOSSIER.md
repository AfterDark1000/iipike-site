# ХПИИ / Досье

Самостоятельный спецпроект, не рубрика. Первый материал — расследование GPT-7. Управляет только главред через /admin/dossier/ с существующим входом GitHub. Список ID хранится в data/dossier.json, новое включение ставится первым. На главной — первые три, полный архив — /dossier/. Статьи остаются в собственных рубриках и обычном архиве. Публикационные даты, адреса, текст, изображения, RSS, Дзен и очереди не меняются.

API /api/dossier: GET возвращает актуальный список и SHA; POST принимает ровно action=add/remove, article_id, config_sha. Worker проверяет владельца, published news.json, точную версию config, сохраняет только data/dossier.json. Ответ о сохранении не является подтверждением развёртывания. GitHub Actions пересобирает архив, блок главной и маркеры существующих статей, безопасно повторяет при конкурирующих обновлениях. Полчасовой запуск — запасной путь. Обычный publisher сохраняет оформление Досье при штатной пересборке.

Оригинальная обложка остаётся без изменения: рамка и маркер задаются CSS/HTML. Отдельный статус не назначается автономным редактором. Для исправления ошибочного включения — «Исключить» в админке, статья не удаляется.

Проверка: python3 scripts/build_dossier.py --check; python3 -m unittest discover -s tests -p test_site_dossier.py -v; node --test admin-auth-worker/tests/dossier.test.mjs. После deploy /health должен вернуть dossier_management:true. Не утверждать готовность API по одному успешному merge.
