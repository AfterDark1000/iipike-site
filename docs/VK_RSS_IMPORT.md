# ХПИИ → ВКонтакте: отдельный RSS с JPEG-обложками

Экспорт: https://iipike.ru/vk-rss.xml (независим от feed.xml и dzen-rss.xml).
Никаких API ВК или секретов: источником служат только опубликованные статьи сайта.

## Безопасное включение

- Исходное состояние: data/vk_rss_export.json — mode=standby. Лента валидна, но **пустая**, чтобы случайно не опубликовать заново старые новости.
- После согласования пробной публикации выбрать **будущую** дату начала в UTC, задать mode=active и cutover_at_utc="YYYY-MM-DDTHH:MM:SSZ". В RSS попадут только статьи с published_at_utc >= cutover и без исходного dzen_id.
- При выходе новой утверждённой статьи генератор создаёт JPEG-копию обложки (assets/vk/<slug>.jpg), затем обновляет vk-rss.xml. Оригинальная WebP/PNG/JPEG-обложка остаётся без изменений.
- ВК: Управление → Дополнительно → RSS → Импорт в сообщество. Ссылка — https://iipike.ru/vk-rss.xml. **«Публиковать в виде статьи»** и **«Не указывать ссылку в посте»** оставить выключенными.
- Одновременный импорт RSS и старый VK-кросспостинг способны создать дубли. Для теста проверить **одну новую** запись и подтвердить, что фотография действительно прикреплена к записи, а не только отображается как превью ссылки. Только после этого отключать старую VK-ветку.
- Выключение: standby и null cutover, затем пересборка и отключение импорта в ВК. Смена режима генератора сама по себе не переключает настройки ВК.

## Формат и безопасность

RSS 2.0 содержит title, link, guid, pubDate, description (первый элемент — <img>), а также JPEG enclosure.
Размер JPEG ограничен 1280 px по ширине; источник — существующий проверенный assets/editorial/<slug>.(webp|jpg|jpeg|png).
Не импортируются архив Дзена, черновики, записи без опубликованной HTML-страницы, публикации до cutover и обложки с несовпадающим slug.
Генерация VK RSS при выпуске сайта — **необязательный шаг**: ошибка импорта не должна блокировать публикацию сайта.

Ручная пересборка: python3 scripts/build_vk_rss.py
Проверка без записи: python3 scripts/build_vk_rss.py --check
Нужен Pillow, который уже устанавливается в workflow планировщика.

**Важно:** корректный RSS не гарантирует, что ВК перенесёт изображение; требуется проверка конкретного поста на стене.
