## Как воспроизводится отбор

Анализатор читает сохранённые публичные списки IT, науки, бизнеса, новостей и поиск по нейросетям. Для каждого списка он самостоятельно формирует небольшую очередь карточек: и с тематическими признаками, и без них. Очерёдность на этом шаге учитывает частоту выхода и покрытие каталога. Поисковая проверка связывает карточку с редакцией и подтверждает тему двумя независимыми материалами издателя. Единственный материал, описание профиля и число подписчиков сами по себе в основную очередь канал не добавляют. Опрос карточек и результаты редакционных проверок сохраняют происхождение в JSON. [IT](https://dzen.guru/channels?topicId=12) · [Наука](https://dzen.guru/channels?topicId=18) · [Бизнес](https://dzen.guru/channels?topicId=3) · [Медиа](https://dzen.guru/channels?topicId=19) · [Публичный рейтинг IT](https://zenstat.ru/rating/channels/it/)

Пилотный приоритет начинается с медианы 300. Резерв 100–299 нужен для тематических медиа с более скромным охватом. Минимальная частота — четыре материала за 30 дней. Средние значения за месяц используются только для проверки сомнительной маркировки медианы. При повторном запуске указываются локальные HTML-файлы, время чтения профилей и сохранённые ссылки на тематические подтверждения. Анализатор работает без сети. [Код](../scripts/dzen_channel_shortlist.py)

```console
python scripts/dzen_channel_shortlist.py --catalog 'https://dzen.guru/channels?topicId=12' /path/to/it.html
```

К моменту входа применяется отдельный фильтр из A.4/A.5. У новой статьи нужны ИИ-тема, точная дата, возраст до 30–60 минут и 0–3 открытых комментария. Её просмотры остаются наблюдением. В эту работу вошёл выбор каналов, поэтому список не содержит находок для немедленного комментирования.

Публичные страницы использованы в рамках текущих правил Dzen Guru. Допуск к регулярному сбору или хранению данных из внутреннего `/api/v3/launcher/export` по-прежнему не подтверждён. Правила для роботов и доступность ответа сами по себе не подтверждают такой допуск. В этой работе внутреннюю выдачу, расписание, пагинацию и живую очередь не запускали.
