# ХПИИ — регрессионные проверки художественного разнообразия v1.5

Этот справочник применяй при аудите или проверке обновления. Сценарии ниже — логические, их прохождение не равно успешной генерации картинок.

## Базовые проверки

1. **9 направлений, без принудительного круговорота.** В документе перечислены все девять, включая авторскую печатную графику, предметную сценографию и экспериментальную типографику. Художник выбирает подход по смыслу, а не по порядковому номеру.
2. **Печатная графика действительно резцовая.** При лицензиях или конфликте можно задать резцовый штрих и двоичную печатную массу. Фотографический портрет, покрытый фильтром «линогравюра», не проходит.
3. **Предметная сценография действительно материальна.** Для замены окружения в видео показать, например, осязаемый механизм смены миниатюрной декорации. Просто гладкая 3D-сцена с человечком не проходит.
4. **Типографика сама несёт факт.** Для скорости или ограничения буквы и проверенные цифры могут быть предметами изображения. Нельзя выдумывать цифры, делать их нечитаемыми или возвращать старую рекламную колонку текста.
5. **Зацепка и точность одновременно.** Сцена должна давать конкретный интерес к новости и не обещать факт, которого нет. Кричащие лица и стрелки сами по себе не проходят тест.
6. **Визуальный паспорт.** При доступных последних 8–12 изображениях сравнивать материал, пространство/ракурс, действие/динамику, типографику, цвет/свет, эмоцию, механизм интереса. При отсутствии прошлых изображений честно указать ограничение.
7. **Не уравнивать стиль с цветом.** Тот же герой и предмет справа при заменённом цвете не считается новым решением. Две фундаментальные перемены в устройстве кадра могут быть достаточны, если действие и зацепка стали самостоятельными.
8. **Не натягивать стиль на новость.** При рядовом релизе не изображать катастрофу; при отсутствии релевантной числовой информации типографический стиль необязателен.
9. **Адаптация 4:5 не включает творческий антиповтор.** Сохранять утверждённую концепцию, характер оригинала, лица и текст.
10. **Не объявлять победу без просмотра.** Результат успешен лишь после проверки реального изображения, миниатюры и фактов; реальный эффект на CTR требует данных площадки.

## Контрольная тройка для реального визуального теста

- **Новый механизм для видеозамены окружения:** проверить сильный предметный парадокс в миниатюре вместо общей красивой сцены с маленьким неподвижным персонажем.
- **Спор о лицензии ИИ-кода:** попробовать резцовую печатную форму, не копирующую газетный панк-коллаж и прежнюю красно-чёрную массу.
- **Числовой результат модели:** построить изображение из строго подтверждённых знаков и букв с читабельностью в карточке, а не превращать графику в миниатюрную таблицу.

Без доступных сгенерированных картинок оценивать можно только связность инструкций. Не выдавать логическую проверку за доказательство визуального разнообразия или прироста кликов.
