# ХПИИ — полная копия инструкций существующего художника

**Источник:** личный плагин `ХПИИ — Художник` / `hpii-artist` (`plugins_6ad84b2be1a88191ab9bea0a4730df9a`), версия **1.5.2**, по состоянию на 18 ноября 2026 года.

Это **копия всех девяти текстовых файлов навыков и художественных справочников**, дословно перенесённых из действующего плагина. Сохраняются внутренние относительные ссылки `references/*.md`, включая стиль, антиповторы, композицию, тестовые сценарии и правила передачи публикаций. Метаданные упаковки `plugin.json` и `.codex-plugin/plugin.json` не копировались: они не являются художественными инструкциями и содержат личные сведения автора.

## Входные точки

- [**Главный художественный навык**](skills/hpii-cover/SKILL.md) — арт-дирекция, проверка содержания, выбор художественной техники, вариативность, контроль результата.
- [**Обязательный визуальный стандарт**](skills/hpii-cover/references/HPII_Cover_Standard.md) — полные требования ХПИИ.
- [Художественные приёмы](skills/hpii-cover/references/artistic-toolkit.md) и [композиционные возможности](skills/hpii-cover/references/composition-toolkit.md).
- [Сценарии проверки арт-дирекции](skills/hpii-cover/references/art-direction-tests.md), [регрессионные производственные тесты](skills/hpii-cover/references/production-regression-checks.md), [тесты непохожести](skills/hpii-cover/references/style-diversity-regression.md).
- [**Работа с автономными редакционными черновиками**](skills/hpii-auto-cover/SKILL.md) — версии v1–v5, отклонения, GitHub SHA, вывод кандидатной обложки на утверждение.
- [**Ручной режим публикационной передачи**](skills/hpii-publication/SKILL.md) — только по отдельному прямому распоряжению владельца; **автономная задача художника не имеет права его вызывать для публикации**.

## Для автономного художника (задача ChatGPT)

**Начинай с [docs/ARTIST_AUTONOMOUS_AGENT.md](../ARTIST_AUTONOMOUS_AGENT.md).** Читай из `main` эти собственные художественные инструкции — плагин для чтения не нужен. В обязательном порядке учитывай [docs/AUTO_ARTIST_HANDOFF.md](../AUTO_ARTIST_HANDOFF.md) и актуальные данные `editorial-intake`. 

**Не путать модель с источником правил.** Перенос текста в GitHub не назначает модель Sol 6.2, не гарантирует доступ к ChatGPT Images и не решает автоматически транспортировку реальных WebP-байтов в GitHub. Если задача работает без нужного генератора или доступа к байтам, она должна фиксировать блокировку, а не использовать FLUX, не создавать фиктивные WebP и не объявлять успех.

**Обновление:** эта копия зафиксирована на **v1.5.2**. При будущем обновлении плагина зеркало тоже следует синхронизировать; не заявлять о совпадении с новой версией без повторной сверки исходных файлов.
