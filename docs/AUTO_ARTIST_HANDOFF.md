# ХПИИ — передача утверждённых автодрафтов нашему художнику

**Действующий исполнитель: личный плагин `ХПИИ — Художник` / `hpii-artist` (версия 1.5.0 на 18 ноября 2026), а не Cloudflare FLUX.** Для основного редакционного конвейера не создавать альтернативного генератора и не менять внутренний визуальный стандарт плагина. Обложка должна быть такой же авторской и разнообразной, как при обычных командах `@ХПИИ — Художник`.

## Откуда получать художественное задание

Источник истины — ветка `editorial-intake` репозитория `AfterDark1000/iipike-site`:

- `editorial_inbox/auto_drafts/<article_id>.json` — текст, `cover_brief`, `article_id`, `revision`, `updated_at` и источники;
- `editorial_inbox/auto_decisions/<article_id>-r<revision>.json` — отдельное подтверждение текста главредом;
- `editorial_inbox/auto_covers/<article_id>-r<revision>-v<version>.webp` — **неутверждённый** кандидат обложки;
- `editorial_inbox/auto_covers/<article_id>-r<revision>-v<version>.json` — статус `ready_for_cover_review`, SHA исходников/картинки и размеры;
- `editorial_inbox/auto_cover_decisions/` — отдельное решение главреда по обложке.

Кандидат на обложку доступен, если `draft.status == ready_for_review`, точный текст имеет `decision.action == approve_text` и `decision.status == text_approved_cover_pending`, а `decision.draft_blob_sha` совпадает с **актуальными байтами** черновика, `article_id`, `revision` и `updated_at` совпадают. При наличии уже готового кандидата не создавать дубль. Не брать материалы, уже переданные в `auto_handoffs`.

При выборе следующей берём первое подходящее по дате подтверждения текста (`decided_at`), а при равенстве — `pool_sequence`, `article_id`. Не подменять этот порядок новым поиском новостей.

## Действия существующего художника

1. Прочитай свою **встроенную** инструкцию `skills/hpii-cover/SKILL.md` вместе с визуальным стандартом. Затем прочитай весь утверждённый автодрафт, `cover_brief` и первоисточники. Не делай обложку по одному названию ID. Сравни с последними реально доступными обложками; не заявляй о сравнении недоступных.
2. Создай **одну** авторскую художественную горизонтальную обложку 16:9 через штатный генератор изображений ChatGPT, а не FLUX. Грамотный русский заголовок, художественное разнообразие и отсутствие псевдотекста обязательны. Просмотри фактический результат и проверь соответствие новости.
3. Преобразуй реальные байты изображения в WebP, желательно 1600×900, до 800 КБ, подтверди декодируемый WebP и 16:9. Если из среды невозможно передать байты в GitHub, не выдавай это за готовую обложку и не создавай JSON `ready_for_cover_review`.
4. Сохрани в `editorial-intake/editorial_inbox/auto_covers/<article_id>-r<revision>-v1.webp` (или в следующую одобренную версию при доработке) **и только потом** метаданные соответствующей версии. Точная схема JSON и проверка SHA изложены в `docs/AUTO_COVER_ARTIST_PILOT.md`; независимая проверка: `scripts/check_auto_cover_pilot.py`. Никакой записи прямо в `editorial_inbox/covers/` без отдельного решения главреда.
5. Перечитай оба сохранённых файла и покажи результат в `https://iipike.ru/admin/auto-editor/` для двух решений: «Утвердить обложку» / «Переделать». До подтверждения **не писать** боевую статью, обложку, Threads, X, Дзен и не запускать публикацию.

## Первый текущий запрос

**Кандидат:** `avtor-virusnykh-rolikov-trollit-ii-rekruterov-kro-b0f0e86e2a184d00`, **ревизия 3**, текст главредом утверждён. Тема — постановочный скетч Ника Рида: на собеседовании человек с кроссовком на голове, вымышленная ИИ-интервьюер Карен; нельзя представлять как подлинную запись Burger King. Отклонённая FLUX-картинка версии v1 из `auto_covers` удалена, её не использовать как художественный референс. До начала работы обязательно перечитать актуальные черновик и решение в GitHub.

## Автоматизация и ограничение вызова

GitHub может **подготовить/выявить** готовую задачу по подтверждённому тексту и проверить сохранённый результат, но **не умеет сам вызвать личный ChatGPT-плагин `ХПИИ — Художник`**. Наличие инструкции, cron или workflow **не означает**, что настоящий художник получил задание и начал рисовать. Не заменять его вызовом FLUX. Вызов художника должен быть явно подтверждён в поддерживаемом ChatGPT-процессе (например, сообщением в чате этого плагина) либо через отдельную проверенную интеграцию с исполнителем. Старая запланированная задача «ХПИИ — Автономный художник» остаётся отключённой до проверки, что она действительно исполняет собственный художественный стандарт и доставляет настоящие WebP-байты.

**Безопасная команда в существующем чате плагина:**

> Возьми следующий утверждённый автодрафт ХПИИ для обложки. Прочитай `docs/AUTO_ARTIST_HANDOFF.md` в `AfterDark1000/iipike-site`, выбери работу по этому регламенту и действуй как наш собственный «ХПИИ — Художник». Никакого FLUX, экспериментального раздела или прямой публикации; только кандидат WebP в `auto_covers` и последующее решение в админке.
