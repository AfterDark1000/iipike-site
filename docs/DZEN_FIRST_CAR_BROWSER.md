# «Первый вагон» в браузере

[Открыть «Первый вагон»](https://htmlpreview.github.io/?https://github.com/AfterDark1000/iipike-site/blob/51b74f2470974f1923f9455964bc6d26470c5d02/lab/dzen-first-car/index.html)

Ссылка фиксирует проверенную версию интерфейса из черновой ветки. Данные читаются напрямую из текущего `commenting-data/commenting/queue.json` при открытии страницы, по кнопке «Обновить» и при возврате на вкладку. Относительно текущего времени браузера показываются материалы младше 24 часов с готовыми репликами. У кандидатов без ссылки на версию статьи в Дзене доступны оригинал и ручной поиск. Метки сохраняются в браузере и не синхронизируются с рабочей админкой. Python, SQLite и токены для этой страницы не нужны. [Задание](https://github.com/AfterDark1000/iipike-site/pull/216#issuecomment-7008494163) · [Рабочий JSON](https://raw.githubusercontent.com/AfterDark1000/iipike-site/commenting-data/commenting/queue.json)

## Проверка открытой страницы

19 ноября 2026 г. в **17:13:59 по Екатеринбургу** Chromium получил HTTP 200 с `Access-Control-Allow-Origin: *`. Тело ответа совпало с файлом из актуального на момент проверки коммита `bb994c68fe122694c4c84e76c5da55d49b1cc880` ветки `commenting-data`. В браузере было **3 кандидата с готовыми репликами** из iXBT, iGuides и Hi-Tech Mail. У всех трёх отсутствовала прямая ссылка на Дзен. Файл был обновлён в **14:28:44**, поэтому интерфейс показал предупреждение о возрасте снимка и ошибке источника МК. Архивная статья AndroidInsider в выдачу не попала. [Проверенная версия JSON](https://github.com/AfterDark1000/iipike-site/blob/bb994c68fe122694c4c84e76c5da55d49b1cc880/commenting/queue.json) · [Скриншот](../lab/dzen-first-car/screenshots/browser-live.jpg)

Проверены адреса оригиналов и ручного поиска, копирование полного текста реплики, обновление JSON по кнопке и после перезагрузки, обе ручные отметки и отмена. Обработчик возврата проверен событием `visibilitychange` в Chromium. При имитации сетевой ошибки кандидатный список очистился и появилась ошибка загрузки. После восстановления доступа список загрузился снова.

Архив открывается отдельной вкладкой «Демо · архив». Браузерная очередь читает только рабочий JSON Gemini. Для проверенных возможностей по-прежнему нужен отдельный допустимый источник свежих прямых ссылок и счётчиков Дзена.
