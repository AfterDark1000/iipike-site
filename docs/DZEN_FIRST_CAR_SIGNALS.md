# «Первый вагон». Разведсигналы

С 19 ноября 2026 г. в локальном интерфейсе есть отдельная вкладка **«Разведсигналы»**. Она показывает прямой URL, исходную страницу и время первого обнаружения ссылки. У карточки статус «Не подтверждено», а дата и комментарии Дзена неизвестны. «Открыть в Дзене» ведёт по прямой ссылке. Кнопки «Проверил/не подходит» и «Прокомментировано» сохраняют локальную отметку и снимают сигнал с активного списка. Отмеченные карточки видны до истечения часа с первого обнаружения. Час измеряет давность наблюдения ссылки. Возраст статьи может быть больше. [Задание в PR #216](https://github.com/AfterDark1000/iipike-site/pull/216#issuecomment-7007423792)

## Telegram Client API (MTProto и TDLib)

Официальный клиентский API бесплатен для создания Telegram-клиентов. MTProto доставляет обновления в активное соединение авторизованного пользователя. TDLib реализует клиентскую часть этого механизма. Если в доступном аккаунту канале автор опубликовал прямую ссылку, клиент технически может её получить. Дата и реакции сообщения относятся к Telegram. Автоматический сборщик для внешней SQLite-очереди не подпадает однозначно под разрешённую работу клиента. Сетевой сеанс, запросы к аккаунту и тест задержки не выполнялись. [Telegram API Terms](https://core.telegram.org/api/terms) · [Обновления](https://core.telegram.org/api/updates) · [TDLib](https://core.telegram.org/tdlib)

Условия требуют защищать данные пользователя и соблюдать ожидаемое поведение клиента. Content Licensing разрешает ограниченный отзывный доступ только к данным, строго необходимым для легитимной работы клиента, бота или Mini App, с соблюдением прав правообладателей. Хранение, необходимое для работы клиента, само по себе не разрешает внешний архив чужих каналов. Срок хранения для нашей внешней очереди условия не устанавливают. У Telegram есть отдельное ограничение на сбор и использование данных для разработки, проверки и применения ИИ. В документе описаны узкие исключения с явным продолжающимся согласием всех затронутых пользователей. Переход на пользовательскую сессию и обработка без ИИ сами по себе разрешения на внешний сбор не дают. [Telegram API Terms, §1](https://core.telegram.org/api/terms) · [Content Licensing](https://telegram.org/tos/content-licensing)

## Офлайн-прогон

В тестовом снимке три реальные ссылки из сохранённого каталога ХПИИ. Время их обнаружения выставлено для воспроизведения. Оно не измеряет фактическую задержку публикации или доставки. Сценарий в 15:10 по Екатеринбургу дал **2 активных разведсигнала и 0 карточек строгой очереди**. Вариант URL с `?share_to=link` свернулся в ту же карточку, а ссылка, обнаруженная 70 минут назад по сценарию, скрылась. Повтор импорта не создал новых записей. В Chromium проверены адреса кнопок и обе отметки после перезагрузки. Браузер обращался только к локальному серверу. Если тот же URL независимо проходит строгий фильтр, дубль исчезает из разведсигналов. Метрики, история и решения строгой очереди формируются собственным путём. [Снимок сценария](../lab/dzen-first-car/fixtures/scout-signals.json)

```bash
scout_dir=$(mktemp -d)
python scripts/dzen_first_car.py --db "$scout_dir/history.db" --replay import-signals lab/dzen-first-car/fixtures/scout-signals.json
python scripts/dzen_first_car.py --db "$scout_dir/history.db" --replay serve --as-of 2026-11-19T10:10:00Z
```

Локальный интерфейс открывается на `http://127.0.0.1:8765/`. Импорт вне режима воспроизведения требует `source_policy.status=approved` и `permission_ref`, указывающий на основание для чтения и хранения ссылок. Эти поля фиксируют решение оператора. Импортёр проверяет формат URL и сохраняет первый момент обнаружения, переданный источником. Часовой порог скрывает карточку в интерфейсе. Запись остаётся в SQLite для дедупликации. При подключении поставщика срок хранения должен соответствовать его условиям. Для резервного ручного режима можно впоследствии добавить поле вставки URL с явной отметкой «Добавлено вручную».

**Следующий реальный шаг** — проверить один авторский источник, у которого опубликованы прямые URL и применимые условия чтения, либо начать с каталога собственного канала. Сопоставить две последовательные выгрузки и записать момент первого появления URL в источнике. Для оценки окна комментирования отдельно нужен точный момент публикации в Дзене. Сетевой поставщик и расписание выключены.
