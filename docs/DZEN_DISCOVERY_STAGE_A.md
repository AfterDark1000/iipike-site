# Поиск публикаций Дзена. Этап A

**Результат 18 ноября 2026 года — этап A не пройден.** Бесплатно и автономно удалось получить прямые адреса из официальной карты сайта. Через публичный каталог также удалось найти каналы с ненулевыми оценками охвата. Из чистого сеанса страницы Дзена перенаправляли к авторизации, поэтому проверка свежих статей и живых обсуждений по критериям ТЗ не состоялась. [Issue #215](https://github.com/AfterDark1000/iipike-site/issues/215)

Из 30 адресов один проверен и получил статус `blocked`, остальные 29 имеют статус `found_but_not_checked`. Доля подтверждённых свежих публикаций неизвестна. У 2 340 из 41 949 адресов (5,6%) `lastmod` попадает в последние 30 календарных дней, включая дату замера. Карта содержит только `loc` и `lastmod`, поэтому все даты публикации в выборке оставлены пустыми. Примеры из выборки. В этом окружении прямой запрос Chromium не прошёл проверку TLS из-за хранилища сертификатов браузера. В воспроизводимом прогоне Playwright получает первый HTTPS-ответ через `route.fetch(max_redirects=0)` с доверенным CA среды, а Chromium открывает документ при успешном ответе. Каждый URL проверяется в новом контексте. Сторонние и фоновые запросы страницы отключены. В предварительном прогоне с одним общим контекстом на двух каналах и одной статье встречался HTTP 200. Содержимое там не зафиксировано, а в отдельных чистых контекстах все три URL вернули HTTP 302. Ответы 200 в счётчик проверенных публикаций не включены.

Для допуска в очередь нужны данные о просмотрах и обсуждениях за последние 30 дней по 5–10 публикациям сравнимого возраста (либо доступная меньшая выборка), частота выхода и дата последней статьи. ## Ограничения платформы

- Перед прогоном получены актуальные [robots.txt](https://dzen.ru/robots.txt) и [условия Дзена, редакция от 12.11.2026](https://dzen.ru/legal/ru/termsofuse/index.html). Правила для обычного агента запрещали `/search` и допускали проверенные адреса. Условия ограничивают обход барьеров и действия, увеличивающие просмотры. Пробный обход не переходил на URL авторизации и не воспроизводил счётчики просмотров.
- У стороннего каталога проверены [robots.txt](https://dzen.guru/robots.txt) и [публичная оферта](https://dzen.guru/legal/offer). В испытание вошли публичные HTML-страницы. Путь `/api/` запрещён для обычного агента, к нему не обращались. Публичная аналитика выступала дополнительным источником сигналов, её цифры не сверены с Дзеном.
- Все результаты получены из одного облачного окружения 18 ноября. Доступность с другого сетевого подключения и устойчивость при повторении в последующие дни неизвестны.

## Как воспроизвести

Для HTTPS-проверки и выборки из карт нужен Python 3.11+.

```console
python scripts/dzen_stage_a_probe.py
```

Для браузерной проверки нужны Playwright и Chromium.

```console
python -m pip install playwright
python -m playwright install chromium
python scripts/dzen_stage_a_probe.py --browser
```

Для установленного Chromium доступен параметр `--chromium`. В управляемой сети в `NODE_EXTRA_CA_CERTS` можно указать используемую в ней доверенную цепочку для Node. В этом прогоне использовался системный bundle. Подтверждение TLS включено. Скрипт делает единичные запросы с паузой не менее двух секунд, ограничивает выборку одним файлом каждой карты, проверяет пути по свежему robots.txt и прекращает пробу при изменении проверенной редакции условий. Вывод — JSON в stdout. Прогон не требует входа, платных ключей или подписок.

**Переход к этапу B преждевременен.** Для продолжения нужен допустимый способ получать тематические статьи с подтверждёнными датами и проверять обсуждения и охваты на нескольких недавних публикациях одного канала. В этом испытании карта сайта дала адреса, а каталог дал численные сигналы по каналам. Связать эти данные на уровне публикаций и подтвердить живую аудиторию не удалось.
