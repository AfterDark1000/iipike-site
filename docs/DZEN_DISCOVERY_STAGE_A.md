# Поиск публикаций Дзена. Этапы A и A.1

**Статус на 18 ноября 2026 года — владелец вручную открыл одну контрольную статью. Автономный сбор в этапе A.1 остаётся непроверенным.** Прямые адреса доступны в официальной карте сайта. Для первичной проверки Playwright запрашивал только первый документ, с выключенным JavaScript и без загрузки подресурсов. HTTP 302 в этом режиме устанавливает наличие первого перехода к SSO. По нему нельзя определить, вернётся ли штатный Chrome к статье или увидит форму входа. [Issue #215](https://github.com/AfterDark1000/iipike-site/issues/215) · [Уточнение владельца в PR #216](https://github.com/AfterDark1000/iipike-site/pull/216#issuecomment-6983676213)

## A.1. Штатная навигация с JavaScript

Владелец сообщил, что контрольная статья открывается в Chrome и Яндекс Браузере, и прислал снимок мобильной страницы. На снимке видны начало статьи, заголовок «Почему мы не смогли просто попросить AI «быть Сократом»», канал **AI-MARS.PRO**, 6 подписчиков, 10 просмотров и метка публикации «3 мес». Это одна статья, открытая в двух браузерах по сообщению владельца. Точная дата, отдельное имя автора и число комментариев по этому снимку неизвестны. Блок обсуждений в кадр не попал. Состояние авторизации и цепочка редиректов в пользовательских браузерах не наблюдались. [Контрольная статья](https://dzen.ru/a/an2NK2wTexfqvqGD)

В Cloud Desktop открыли окно Chromium и попытались начать просмотр первой контрольной статьи. До подтверждённого открытия страницы автоматическая проверка безопасности отказала в доступе к вкладке и отклонила навигацию. Причиной указано отсутствие разрешения браузера. Политика запретила повтор через другой интерфейс. Итоговый URL, видимый заголовок, автор, дата публикации и обсуждения в браузере остались неизвестными. Гостевой режим и инкогнито отключены политикой управляемого Chromium, поэтому изоляция открытого окна не была подтверждена. Сеанс владельца не использовался.

Отдельно повторили разрешённые первые HTTPS-запросы к трём прямым адресам с паузой между запросами. Каждый адрес опубликован в другом источнике. Третий выбран как контроль небольшого автора по её собственному описанию. Имена авторов и каналов взяты из источников ссылок.

Выборка 5–10 последних материалов не запускалась. Этап B не начат.

### Повторение проверки A.1

Для разового просмотра открыть три адреса из таблицы через адресную строку обычного Chrome в новом профиле. Оставить JavaScript и загрузку ресурсов включёнными. Записать итоговые домен и путь без параметров SSO, видимые заголовок, дату, автора, состояние блока обсуждения и доступные счётчики. При интерактивном запросе входа, CAPTCHA или явном отказе зафиксировать экран и остановиться. К автоматизации переходить после подтверждения штатного сценария и проверки правил для его сетевых переходов.

Первый HTTPS-ответ можно отдельно проверить командой ниже. Замена URL на два других из таблицы воспроизводит контроль. Команда выводит только HTTP-статус.

```console
curl --silent --show-error --max-time 20 --output /dev/null --write-out '%{http_code}\n' https://dzen.ru/a/an2NK2wTexfqvqGD
```

У одного адреса проверен первый ответ HTTP 302, остальные 29 имеют статус `found_but_not_checked`. Историческая метка `blocked` для этого редиректа означает остановку пробника на первом ответе, а в новых прогонах это `redirect_not_followed`. Доля подтверждённых свежих публикаций неизвестна. У 2 340 из 41 949 адресов (5,6%) `lastmod` попадает в последние 30 календарных дней, включая дату замера. Карта содержит только `loc` и `lastmod`, поэтому даты публикации в выборке оставлены пустыми. Примеры из выборки. [Адрес 1](https://dzen.ru/a/avzrF7LU2Bb_QNqN), [адрес 2](https://dzen.ru/a/avz3E2GKCzOWJAsG), [адрес 3](https://dzen.ru/a/avxLwM3gh2vppMAJ)

В этом окружении прямой запрос Chromium не прошёл проверку TLS из-за хранилища сертификатов браузера. В воспроизводимом прогоне Playwright получает первый HTTPS-ответ через `route.fetch(max_redirects=0)` с доверенным CA среды, а Chromium открывает документ при успешном ответе. Каждый URL проверяется в новом контексте. Сторонние и фоновые запросы страницы отключены. В предварительном прогоне с одним общим контекстом на двух каналах и одной статье встречался HTTP 200. Содержимое там не зафиксировано, а в отдельных чистых контекстах все три URL вернули HTTP 302. Ответы 200 в счётчик проверенных публикаций не включены.

## Ограничения платформы

- Перед прогоном получены актуальные [robots.txt](https://dzen.ru/robots.txt) и [условия Дзена, редакция от 12.11.2026](https://dzen.ru/legal/ru/termsofuse/index.html). Правила для обычного агента запрещали `/search` и допускали проверенные адреса. Условия ограничивают обход барьеров и действия, увеличивающие просмотры. Пробный обход не переходил на URL авторизации и не воспроизводил счётчики просмотров.
- У стороннего каталога проверены [robots.txt](https://dzen.guru/robots.txt) и [публичная оферта](https://dzen.guru/legal/offer). В испытание вошли публичные HTML-страницы. Путь `/api/` запрещён для обычного агента, к нему не обращались. Публичная аналитика выступала дополнительным источником сигналов, её цифры не сверены с Дзеном.
- Автоматические сетевые замеры получены из одного облачного окружения 18 ноября. Отдельное ручное наблюдение получено от владельца. Воспроизводимость автоматического доступа в другой сети и при повторении в последующие дни неизвестна.

## Как воспроизвести исходный прогон A

Для HTTPS-проверки и выборки из карт нужен Python 3.11+.

```console
python scripts/dzen_stage_a_probe.py
```

Для просмотра первого HTML-документа без JavaScript и переходов нужны Playwright и Chromium.

```console
python -m pip install playwright
python -m playwright install chromium
python scripts/dzen_stage_a_probe.py --browser
```

Для установленного Chromium доступен параметр `--chromium`. В управляемой сети в `NODE_EXTRA_CA_CERTS` можно указать используемую в ней доверенную цепочку для Node. В этом прогоне использовался системный bundle. Подтверждение TLS включено. Скрипт делает единичные запросы с паузой не менее двух секунд, ограничивает выборку одним файлом каждой карты, проверяет пути по свежему robots.txt и прекращает пробу при изменении проверенной редакции условий. Вывод — JSON в stdout. Прогон не требует входа, платных ключей или подписок.

**Переход к этапу B преждевременен.** Для продолжения нужен допустимый способ получать тематические статьи с подтверждёнными датами и проверять обсуждения и охваты на нескольких недавних публикациях одного канала. В этом испытании карта сайта дала адреса, а каталог дал численные сигналы по каналам. Связать эти данные на уровне публикаций и подтвердить живую аудиторию не удалось.
