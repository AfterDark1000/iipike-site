# ХПИИ: пилот поиска прямых публикаций Дзена для комментинга

Статус: **эксперимент, НЕ подключён к рабочему /admin/commenting/**.
Цель — заменить сомнительные поисковые ссылки на конкретные статьи Дзена.
Никакой публикации комментариев и никаких запросов к dzen.ru от сборщика.

## Что делает

- **Brave Search API** находит прямые URL через общие тематические запросы (включая небольшие каналы, не только СМИ). Дата индексации **НЕ считается датой публикации**: результат без подтверждённой даты попадает в группу needs_publication_date.
- **Keys.so API** получает топ новых публикаций и публикации наблюдаемых каналов, включая дату, просмотры и комментарии, если данные вернулись. По умолчанию список наблюдаемых каналов пуст, чтобы не имитировать наличие авторов.
- Принимаются только прямые адреса вида https://dzen.ru/a/ARTICLE_ID и https://dzen.ru/media/id/CHANNEL_ID/POST_ID. Ссылки на поиск, на каналы, внешние сайты и незнакомые форматы отбрасываются.
- Фильтр тематики, возраст публикации не больше 72 часов, удаление точных дублей, максимум две публикации с одного канала, небольшой бонус каналам до 10 000 подписчиков **только если число подписчиков действительно известно**.
- Ищет каналы по URL, собирает channel_candidates для дальнейшего расширения охвата. Не утверждает, что есть реальные просмотры/комментарии там, где данных нет.
- Группа ready означает: провайдер передал прямой URL и дату в пределах заданного периода. **Это не проверка доступности статьи или открытости комментариев на dzen.ru**. До прямой проверки у ссылки статус provider_link_unopened.
- Группа needs_publication_date — прямой URL найден в поисковом индексе, но дата публикации неизвестна. Нельзя автоматически ставить в рабочую очередь как свежий.

## Локальный запуск

Нужен Python 3.11+; внешних Python-пакетов нет.

Тесты:

    python3 -m unittest discover -s tests -p 'test_dzen_comment_discovery.py' -v

Пробный офлайн-ввод (JSON с ключами keys и brave, содержащими списки результатов):

    python3 scripts/dzen_comment_discovery.py --fixture path/to/sample.json --output /tmp/dzen-discovery.json

Реальные источники (ни один ключ в GitHub не коммитить):

    export KEYS_SO_API_TOKEN="..."
    export BRAVE_SEARCH_API_KEY="..."
    python3 scripts/dzen_comment_discovery.py --live --output /tmp/dzen-discovery.json

Можно использовать только один ключ. Если нет ни одного, сборщик сообщит not_configured и завершится с кодом 2.
В консоль не выводятся секреты, сырые HTTP-ответы и полный текст статей.
Провайдеры могут быть платными и устанавливают лимиты; пока нет расписания, регулярных платных вызовов не будет.

## Доступ и затраты

- Keys.so предоставляет API только на тарифах «Профессиональный» и «Корпоративный» по справке https://help.keys.so/helpie_faq/est-li-integratsiya-po-api-pochemu-u-menya-net-polya-api. Не оформлять платную подписку ради одного теста без предварительной оценки.
- Brave публикует ориентир $5 за 1000 запросов и месячный кредит $5 при соблюдении условий аккаунта: https://brave.com/blog/most-powerful-search-api-for-ai/. При четырёх поисковых запросах на один прогон стоимость невысока, но индекс может плохо покрывать Дзен, поэтому сначала один ручной прогон и проверка результата.
- Успешные офлайн-тесты проверяют код и фильтры, а не наличие доступных API-ключей или реальные результаты поиска.

## Отбор и развитие

Конфигурация: data/commenting_dzen_discovery.json.
Поле channels — URL каналов Дзена (малых, средних, любых), требующих отдельного наблюдения в Keys.so. Каналы можно добавлять постепенно после ручной проверки их тематики и активности.
Провайдеры не гарантируют полноту охвата, доступность ссылок, отображение статистики и скорость индексации. «Статья найдена» не равно «комментарии доступны».

Отчёт содержит число просмотренных результатов, отбраковку и две раздельные группы.
Для сравнения с текущей RSS-очередью замеряем: число прямых URL, дату публикации, уникальные каналы, долю небольших авторов (только при известных подписчиках), возможность открыть статью и комментировать вручную. Не судим об успехе по суммарному количеству ссылок.

## Граница интеграции

Эта ветка не редактирует scripts/commenting_queue.py, data/commenting_sources.json, commenting/queue.json, admin/commenting/ или автоматическую генерацию Gemini.

**Прежде чем менять рабочую очередь**, нужны реальные вызовы API и ручная проверка 20–30 найденных URL. В отдельном PR сделать импорт свежих проверенных ссылок в комментинг и отложить переработку Gemini на следующий этап.
