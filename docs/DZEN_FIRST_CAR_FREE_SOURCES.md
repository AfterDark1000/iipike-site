# Бесплатные источники для «Первого вагона»

**Проверка 19 ноября 2026 г.** Бесплатный источник, пригодный для заполнения очереди по шести каналам, пока не подтверждён. В публичном RSS Хабра наблюдались недавние ИИ-публикации самого Хабра. Авторские анонсы в Telegram и «Сетке» действительно содержат отдельные прямые ссылки Дзена. Ни в одном проверенном варианте нет одновременно подтверждённого доступа для мониторинга, точного времени публикации в Дзене и свежих счётчиков обсуждений. ### Что разрешают опубликованные условия Дзена

В редакции от 12 ноября 2026 г. §5.3.1 описывает пользовательский контент как не предназначенный для сбора и дальнейшего распространения третьими лицами. §6.2 привязывает использование сервиса к предусмотренным им целям, §6.3 запрещает вмешательство в работу сервиса и обход ограничений. В сохранённом `robots.txt` маршрут `export` не закрыт правилом для `*`. Из этих документов не следует однозначное право регулярно читать внутренний маршрут и хранить полученные метаданные даже при небольшом частном использовании. Пилот с ответом HTTP 200 установил работоспособность чтения. Интерфейс периодической выгрузки и условия его использования остаются неподтверждёнными. [Условия Дзена](https://dzen.ru/legal/ru/termsofuse/index.html) · [robots.txt](https://dzen.ru/robots.txt) · [Снимок условий и параметры пилота](DZEN_SIX_CHANNEL_PILOT_2026-11-19.json)

## Две живые RSS-ленты и локальный импорт

Выполнено по одному GET на каждую RSS-ленту, обнаруженную через `rel=alternate` на сайте издателя. Часы указаны по Екатеринбургу. В оба ответа зашли без учётных данных. Запросов к статьям, каналам или JSON Дзена не было.

| Лента | Получена | Записей | Принятых ИИ-сигналов за час по времени сайта | Ссылок `dzen.ru/a/` в XML |
| --- | --- | ---: | ---: | ---: |
| [Хабр, «Искусственный интеллект»](https://habr.com/ru/rss/hubs/artificial_intelligence/articles/?fl=ru) | 15:46:58, HTTP 200 | 40 | 2 | 0 |
| [Блог Максима Татаринова](https://blog.tatarinovms.space/index.xml) | 15:46:59, HTTP 200 | 93 | 0 | 0 |

Два сигнала прошли тематический фильтр из пяти записей Хабра с `pubDate` за последний час. Их возраст в момент чтения был 14 мин 13 с и 16 мин 06 с. Момент первого появления записей в RSS неизвестен. Для объединения с Дзеном у обеих записей нет прямого соответствия. У блога Татаринова анонс Qwen3 ASR в «Сетке» содержит прямую ссылку на статью в Дзене, а собственная RSS-лента её не содержит. [Первый сигнал Хабра](https://habr.com/ru/articles/1109824/) · [Второй сигнал Хабра](https://habr.com/ru/articles/1109822/) · [Анонс Qwen3 ASR](https://setka.ru/posts/019dedb7-7e32-75c3-ae98-9c707ec3c564) · [Статья в Дзене](https://dzen.ru/a/afc39PzfhA6doVuX)

К существующему импорту RSS добавлено необязательное поле `dzen_url`, если единственная каноническая ссылка указана издателем в `link` или Atom `link rel="alternate"`. Ссылки в описаниях могут вести на другие статьи, поэтому они остаются вне сопоставления. Первая обработка живых файлов дала два сигнала с `confirmed_on_dzen=false`, повтор дал ноль, в истории Дзена и в очереди осталось ноль. Положительный случай с явной ссылкой и случай двух конкурирующих ссылок проверены на тестовых данных. [Код RSS-адаптера](../scripts/dzen_first_car_rss.py) · [Тесты](../tests/test_dzen_first_car.py)

Для локального воспроизведения на сохранённом RSS Хабра укажите фактическое время его получения. Для снимка этого прогона команда выглядит так.

```bash
python scripts/dzen_first_car_rss.py --db /tmp/first-car-rss.db --channel habr \
  --feed-url 'https://habr.com/ru/rss/hubs/artificial_intelligence/articles/?fl=ru' \
  --as-of 2026-11-19T10:46:58Z /path/to/saved-habr.rss
```

## Решение для запуска

1. **Доступно сейчас.** Оставить бесплатный RSS как предварительный автоматический сигнал там, где правила допускают чтение ленты. Конкретно проверен тематический RSS Хабра. Данные такого сигнала остаются в импортере RSS. Для мониторинга публикаций именно в Дзене полезнее всего явный анонс от редакции со ссылкой на статью. Штатный Bot API подходит для доставки таких анонсов из подключённых редакцией каналов, если использование разрешено условиями. Покрытия нужных каналов этим способом пока нет.
2. **Когда появится подходящий поставщик.** Для того же URL нужны подтверждённые `published_at`, `comments`, `comments_open`, счётчики из зрелой истории канала и опубликованные условия, которые покрывают получение и локальное хранение. Тогда достаточно сформировать существующий JSON `import` с фактическим `observed_at` и ссылкой на условия `permission_ref`. Сначала на небольшой группе нужно измерить долю статей, которые поставщик обнаружил за 30 и 60 минут. Разность рассчитывается от точного времени Дзена до первого наблюдения того же канонического URL. Для очереди также нужна текущая отметка об открытом обсуждении и 0–3 комментариях. [Контракт и пороги очереди](DZEN_FIRST_CAR_PIPELINE.md)

Текущая очередь рассчитана на подтверждённые данные. Сетевой поставщик и расписание в этой итерации не подключены.
