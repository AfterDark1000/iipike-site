# ХПИИ — копилка идей

Здесь храним задумки для проекта «Хроники Пикирующего ИИ», которые сейчас не планируем реализовывать, но хотим сохранить. Это **не очередь задач и не план работ**: запись идеи не запускает разработку, закупки, производство или публикацию.

## Как пользоваться

- Новые идеи добавляем в этот файл отдельными карточками с очередным ID, датой, направлением и кратким описанием. Можно записать сырую мысль — детали уточним позже.
- Статусы: **отложено** (сохранена на будущее), **обсуждаем** (оцениваем возможность), **в работе** (отдельно принято решение начать), **реализовано**, **отказались**.
- Не удаляем реализованные или отклонённые идеи: меняем статус, чтобы сохранялась история.
- По запросам «запиши идею», «покажи копилку идей», «вернёмся к идее №…» используем этот файл. Здесь не размещаем новости, черновики статей и текущие технические инциденты.

## IDEA-001 — Еженедельный видеообзор новостей ИИ

- **Дата:** 15 ноября 2026
- **Направление:** Видео / YouTube и другие подходящие площадки
- **Статус:** отложено
- **Формат:** полноценный горизонтальный выпуск (16:9), не Shorts
- **Суть:** раз в неделю делать видеосводку самых интересных, необычных и цепляющих новостей ИИ за прошедшую неделю. Отбирать не все новости подряд, а самые достойные просмотра; подавать с сильными, но достоверными заголовками, живым рассказом и монтажом.
- **Возможная подача:** пользователь может самостоятельно озвучивать выпуски своим голосом вместо синтезированной речи.
- **Что потребуется при возвращении к идее:** подобрать хороший микрофон для качественной записи голоса, определиться с длительностью, сценарием, видеорядом, монтажным процессом и сделать пробный выпуск.
- **Решение сейчас:** только сохранить идею; производство и покупку оборудования не начинать.
