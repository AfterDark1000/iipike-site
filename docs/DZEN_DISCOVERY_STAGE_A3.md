# Дзен. Живой эксперимент A.3

18 ноября 2026 года прототип нашёл **две статьи из двух каналов**. Анонимные запросы к выдаче каналов Дзена вернули HTTP 200, прямые адреса, точное время публикации, ненулевые просмотры и по одному комментарию на выбранную статью. Для повтора нужны Python 3.11 или новее и сетевой доступ к Дзену. [Задание A.3](https://github.com/AfterDark1000/iipike-site/issues/215#issuecomment-6987148255) · [Исходный код](../scripts/dzen_stage_a3_probe.py) · [JSON живого прогона](DZEN_DISCOVERY_STAGE_A3_2026-11-18.json)

Из каждого ответа выбрана одна статья с ненулевыми просмотрами. Приоритет у карточки с большим числом комментариев, при равенстве — с большим числом просмотров. `publisher_id` сверяется с идентификатором канала, `link` приводится к прямому адресу статьи удалением параметров. Время берётся из `publication_date` (Unix-секунды), относительная метка — из `creation_time`. Число комментариев берётся из `socialInfo.commentCount`. Если оно отсутствует, прототип записывает `null` с причиной. Оба счётчика взяты из карточек самого Дзена. Прямые ссылки подтверждены полем `link` в этих карточках. Отдельное открытие страниц статей в A.3 не проверялось.

## Что показали существующие подходы

| Подход | Что увидели в исходниках и в сети |
| --- | --- |
| `dzen-to-md` | Chromium с подставленным User-Agent Chrome, ожидание и прокрутка карточек, извлечение заголовка, прямой ссылки и относительной даты из DOM. Модуль статьи получает основной текст и удаляет элементы реакций. Извлечение просмотров и комментариев в изученных файлах отсутствует. Живой браузерный путь исследован в A.2, где автоматический переход остановили правила SSO. [Исходники](https://github.com/Alexandrsv/dzen-to-md) · [Отчёт A.2](DZEN_DISCOVERY_STAGE_A2.md) |
| `protechno-media-analyzer` | Парсер берёт поля из карточек `/api/v3/launcher/more`, предварительно прогревая сессию с параметром автологина. В A.3 выполнены независимые анонимные GET. По `channel_id=<24-символьный ID>` оба канала ответили HTTP 200, `items=[]` и `channel.status=redirect` внутри JSON. По `channel_id=<короткое имя>` оба дали 404. По `channel_name=techinsider` — HTTP 200, `channel.status=ok`, `items=[]`, а в `channel.source.feed_api_link` Дзен указал путь `/api/v3/launcher/export`. Запросы только с `channel_name` к этому пути дважды дали по странице карточек обоих каналов. [Исходник](https://github.com/TheAlexGrimes30/protechno-media-analyzer/blob/main/dzen_parser.py) |
| Apify | Два коммерческих инструмента заявляют доступ к публикациям. Второй использует резидентские прокси. Маркетинговые описания изучены отдельно от живых результатов. [Parsebird](https://apify.com/parsebird/dzen-scraper) · [Chromium-реализация](https://apify.com/sashaebashu/yandex-dzen-scraper) |

## Границы эксперимента

Перед каждым прогоном проверяются актуальный `robots.txt` для точных путей запроса и отпечаток редакции условий от 12 ноября 2026 года. Правила для экспериментального User-Agent допускали эти GET. В §5.3.1 данные пользователей описаны как не предназначенные для сбора и дальнейшего распространения третьими лицами. §6.2–6.3 ограничивают использование обычным назначением сервиса и запрещают обход ограничений и искусственное увеличение просмотров. Эксперимент включает только два запроса к анонимной JSON-выдаче после проверки правил, с паузой между обращениями, без пагинации, входа, cookies и переходов. Артефакты содержат минимум метаданных двух карточек. HTTP-успех подтверждает техническую возможность. У внутреннего пути не обнаружено публичной документации или гарантий стабильности. Условия регулярного применения и дальнейшего распространения требуют отдельного согласования. [robots.txt Дзена](https://dzen.ru/robots.txt) · [Условия Дзена](https://dzen.ru/legal/ru/termsofuse/index.html)

Из корня ветки выполните команду. При изменении условий, запрете в `robots.txt`, редиректе, ограничении доступа или неожиданном формате пробник остановится и укажет причину в JSON.

```console
python scripts/dzen_stage_a3_probe.py
```

## Как обнаруживать каналы автоматически

1. Публичный тематический раздел Dzen Guru даёт кандидатов по ссылкам на карточки каналов. На этапе A из одного разрешённого раздела извлечено 50 ссылок. В A.3 для двух контролей сверены публичные карточки, короткие имена и идентификаторы. Сводные просмотры и вовлечённость пригодны для предварительного отбора. Канальный sitemap Дзена и открытые ссылки на авторов могут пополнять список кандидатов. Метка `lastmod` sitemap описывает обновление записи. [Каталог](https://dzen.guru/channels?topicId=18) · [TechInsider](https://dzen.guru/channels/techinsider) · [Hi, AI](https://dzen.guru/channels/hiaimedia) · [Результаты этапа A](DZEN_DISCOVERY_STAGE_A.md)
2. После согласования следующей проверки брать ограниченную выборку из 5–10 недавних публикаций на канал. Проверять свежесть, долю материалов с ненулевыми просмотрами и долю с комментариями. Пропуски учитывать отдельно от наблюдаемых нулей. Число подписчиков служит контекстом, чтобы небольшой канал с обсуждениями мог пройти отбор.

Критерий A.3 выполнен. Два канала имеют наблюдаемые просмотры и обсуждения в выдаче Дзена. У Hi, AI на показанной статье два просмотра. Для оценки стабильного охвата нужна выборка публикаций. Автоматический отбор и этап B в этот эксперимент не входили.
