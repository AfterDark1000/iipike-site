## Визуальный стандарт (28.11.2026)

- Приоритет — исходный фирменный цветной знак, по возможности из официального бренд-центра; допустима проверяемая сторонняя копия. Для одноцветного знака использовать подтверждённую фирменную заливку. Чёрный или белый — когда это соответствует фирменной версии.
- Не обесцвечивать уже существующие цветные логотипы ради единообразия. Не выдумывать цвета или геометрию. При отсутствии достоверного знака сохранять буквенную эмблему.
- Хранить локальный безопасный SVG без внешних ресурсов, скриптов и сетевых запросов; записывать источник, SHA и изменения. Проверять читаемость в маленьком размере. Знаки используются только для независимой редакционной идентификации, без заявления о партнёрстве; права на товарные знаки сохраняются.
