# ХПИИ — приёмник статей и обложек (сайт первым)

Это рабочий редактор в ChatGPT, НЕ экспериментальная Gemini/FLUX-редакция.

## Новый порядок

1. Агент присылает сводку. Человек передаёт новость ChatGPT-редактору.
2. Редактор готовит статью для Дзена и посты для Threads и X. По команде человека «берём» сохраняет утверждённые социальные тексты в старые очереди в репозитории AfterDark1000/dzen-telegram-crosspost и ПОЛНУЮ статью в editorial_inbox/stories/<id>.json ЭТОГО репозитория.
3. Обложка из Художника или любого другого чата по прямой команде «отправь обложку редактору» загружается в editorial_inbox/covers/<id>.webp; допускаются также PNG и JPEG. Названия файлов связываются по ТОЧНОМУ стабильному ID, а не по приблизительному сходству названий.
4. Входящие текст и изображение хранятся независимо. Никакой автоматической публикации из одного только текста или изображения. Проверка: python3 scripts/site_first_inbox.py --audit. Статусы: AWAITING_COVER, READY, COVER_AWAITING_ARTICLE.
5. Когда есть оба компонента, на отдельной ветке: python3 scripts/site_first_inbox.py <id> --stage --publish. Команда проверяет источник, утверждение, текст, картинку, совпадение ID, отсутствие дублей, затем создаёт approved JSON и статические страницы, RSS, рубрики и Sitemap.
6. После успешных проверок, PR, слияния и GitHub Pages деплоя статья становится доступной на iipike.ru. Только затем человек вручную публикует её в Дзене.
7. Старый внешний обходчик и кросспостинг на Telegram, VK, Threads, X и другие площадки продолжают работать как прежде, по выходу статьи в Дзене.

Окончательный заголовок Дзена должен быть тем же в статье сайта и в существующих очередях Threads/X. Нельзя переименовать заголовок между сохранением и публикацией в Дзене без синхронного исправления очередей.

## Контракт одобренного текста

Путь: editorial_inbox/stories/<id>.json, поля:

~~~json
{
  "schema_version": 1,
  "id": "sample-unique-news-20261104",
  "status": "editor_approved",
  "approved_by": "human_editor",
  "approved_at": "2026-11-04",
  "title": "Полный окончательный заголовок новости",
  "dzen_title": "Полный окончательный заголовок новости",
  "summary": "Краткое проверенное содержание.",
  "rubric": "news",
  "section": "НОВОСТИ ИИ",
  "source_url": "https://example.org/actual-primary-source",
  "source_title": "Официальный первоисточник",
  "threads_queue_id": "sample-unique-news-20261104",
  "x_queue_id": "sample-unique-news-20261104",
  "related_dzen_ids": [],
  "paragraphs": [
    {"type": "lead", "text": "Полный проверенный первый абзац."},
    {"type": "p", "text": "Полный проверенный следующий абзац."}
  ]
}
~~~

ID: только маленькая латиница, цифры и дефисы, до 72 символов. При правках до выхода сохраняем прежний ID. При наличии связанных архивных статей разрешены только подтверждённые 24-символьные Dzen ID.

Указывать status=editor_approved и approved_by=human_editor разрешается ТОЛЬКО после явного решения пользователя «берём». Это не криптографическая подпись: окончательную публикацию разрешают права GitHub и отдельный релизный PR. Никакой автоматической публикации из экспериментальных черновиков.

Не писать в входящий JSON published, published_at_utc, dzen_id, dzen_url или modified_at_utc. approved_at — дата утверждения текста, НЕ дата выпуска. Реальное UTC-время сайта ставится непосредственно при подготовке публикационного релиза; после этого необходимы PR, CI и успешный деплой.

## Универсальная передача обложки

Система НЕ привязана к чату. Файл может быть создан Художником или обычным чатом. Для отправки нужны реальные байты изображения в данном чате и доступные инструменты GitHub. Тогда ассистент может создать binary blob с base64, добавить его в дерево Git и зафиксировать по точному пути editorial_inbox/covers/<id>.<ext>. Перезапись обложки допустима только с отдельным разрешением пользователя.

Если инструменты не позволяют получить байты текущей картинки, НЕЛЬЗЯ сообщать «отправил»: нужно объяснить, что файл надо приложить в чат с доступом к GitHub. Ссылку на картинку в интерфейсе ChatGPT вместо самого файла НЕ сохранять.

Принимаем декодируемые WebP/PNG/JPEG: 16:9, минимум 780×430, объём 15 KiB–16 MiB. Техническая проверка не выявляет художественные дефекты: собственные оригинальные обложки проверяются человеком по визуальному стандарту ХПИИ; превью Дзена с дополнительными заголовками и логотипами запрещены.

## Что ещё не подключено

Этот этап создаёт репозиторный приёмник, валидатор и безопасную команду сборки. Он НЕ перепрограммирует ЧатGPT-редактора, Художника, внешний обходчик и не запускает автопубликации. До первой реальной проверки доставки изображения нельзя обещать, что команда «отправь» работает абсолютно в каждом произвольном чате.

Проверяем на первой настоящей новости: берём → редакционный JSON в GitHub → обложка из другого чата → site-first release PR → Pages → ручная публикация в Дзене → старый кросспостинг.
