# LG открыла бесплатный API K-EXAONE 2.5 для разработчиков

**LG AI Research** 9 ноября открыла бесплатный доступ к API собственной модели **K-EXAONE 2.5**. Разработчики, стартапы, компании и исследовательские организации могут получить ключ на платформе EXAONE и подключить нейросеть к своим проектам.

K-EXAONE 2.5 — экспериментальная версия корейской модели, дополнительно обученная на основе августовского выпуска. Она предназначена для работы с текстом, программирования и задач ИИ-агентов. API совместим с форматом OpenAI, поэтому разработчикам проще подключать его к существующим приложениям.

LG утверждает, что за восемь недель улучшила совокупные показатели модели более чем на 70%. В тесте AutomationBench, оценивающем автоматизацию работы с онлайн-сервисами, K-EXAONE 2.5 получила 74,6 балла против 74,9 у **DeepSeek V4.1 Flash**. Результаты получены самой LG на открытых наборах задач.

API уже доступен через [платформу EXAONE](https://docs.exaone.ai/en/docs/overview). Пользоваться им можно бесплатно, но действуют ограничения на частоту запросов.
