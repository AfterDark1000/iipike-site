# Claude переписал собственный API и сократил нагрузку на процессоры на 70%

За неделю нейросеть написала первую версию ядра программы, которой ежедневно пользуются клиенты самой Anthropic.

С начала 2024 года к осени 2026-го количество запросов к API **Claude** выросло примерно в **1800 раз**. Написанная на Python система обработки запросов требовала всё больше вычислительных ресурсов. В Anthropic решили перенести её на язык программирования Rust, поручив значительную часть работы собственной нейросети.

## И тут начались проблемы

В апреле новая программа успешно проходила 98% тестов.

Однако при проверке на реальных запросах результаты обработки совпадали со старой версией лишь в четверти случаев. А аудит тестов обнаружил более сотни ослабленных проверок.

**Anthropic** организовала команду ИИ-агентов с координатором, который распределял обнаруженные ошибки между исполнителями. Агенты воспроизводили сбои, исправляли код и отправляли изменения на проверку инженерам.

Комментарии людей сохранялись в общей памяти. Если программист запрещал неудачное решение, следующие агенты уже знали об этом запрете.

Похожий механизм компания представила 23 ноября в [Claude Ship, системе автоматической проверки и исправления программного кода](https://dzen.ru/a/awVbdMsp5G6YhEq9).

## Что получилось?

В сентябре Anthropic перевела клиентский трафик на Rust без остановки сервиса. В техническом отчёте от 25 ноября компания опубликовала результаты:

- Расход ресурсов процессора на запрос сократился примерно на **70%**.
- Потребление оперативной памяти на запрос уменьшилось более чем на **80%**.
- Время ожидания начала ответа в Claude Code сократилось примерно на **20%** по медиане.

К маю 2026 года Claude уже писал более 80% всего кода, который Anthropic принимала в свои проекты.
