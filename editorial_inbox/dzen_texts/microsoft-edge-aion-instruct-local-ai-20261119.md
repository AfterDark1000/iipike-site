# Microsoft поселила ИИ в Edge. Ему не нужен интернет

Теперь браузер сам обрабатывает запросы к нейросети. Текст остаётся на вашем компьютере.

19 ноября **Microsoft** объявила о выпуске **Aion Instruct** — языковой модели с 2,3 миллиарда параметров, которая заменила прежнюю **Phi-4-mini** внутри **Edge**.

Новая модель компактнее предшественницы. По данным Microsoft, на обычных текстовых задачах она показывает сопоставимое качество, а запускать её можно на большем количестве устройств.

Главное изменение касается сайтов.

Через **Prompt API** — специальный программный интерфейс — разработчики получают доступ к нейросети, уже встроенной в браузер посетителя. Например, сайт может поручить ей сократить длинный текст, разобрать документ или подготовить ответ.

Обработка идёт на самом устройстве. Отправлять текст в облачный ИИ-сервис для таких запросов не требуется. После первой загрузки модель работает и без интернета.

**Но пока это эксперимент для разработчиков.** Microsoft открыла доступ к Prompt API на работающих сайтах через программу *origin trial*, участникам которой нужно зарегистрироваться. Сама Aion Instruct уже вышла в общий доступ.

## Нейросеть скачивается не на каждый компьютер

Microsoft объяснила принцип загрузки:

> «Edge загружает Aion Instruct, только когда она впервые понадобится сайту или функции, и только на устройства, которые способны с ней справиться».
> — Команда Microsoft Edge, перевод с английского

Для тестового Prompt API компьютер должен иметь **не менее 3 ГБ видеопамяти**, а на диске потребуется **20 ГБ свободного места**.

Управление находится в настройках Edge — раздел *Copilot и ИИ*, переключатель *On-device AI*. Если отключить локальный ИИ, браузер удалит скачанную модель и прекратит загружать её повторно.

Схожую технологию уже использует **Opera**: [в октябре она открыла сайтам доступ к локальным нейросетям прямо через браузер](https://dzen.ru/a/auMWu1UnvRMpmBgk). Microsoft теперь предлагает разработчикам собственную встроенную модель.

## А что с русским языком?

Microsoft выложила Aion Instruct на **Hugging Face** с открытыми весами под лицензией MIT. Модель обрабатывает контекст до 32 тысяч токенов — этого хватает для работы с объёмными документами и длинной перепиской.

В официальной карточке перечислены восемь языков: английский, немецкий, испанский, португальский, итальянский, французский, китайский и японский.

**Русского среди них пока нет.**

Отдельно Microsoft готовит замену старой локальной модели в самой **Windows**. Распространение Aion среди участников программы Windows Insider намечено на декабрь 2026 года, а для обычных пользователей Windows — на январь 2027-го.

В Edge модель уже выпущена. Для Windows переход ещё впереди.
