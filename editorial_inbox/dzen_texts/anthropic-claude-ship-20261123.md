# Claude теперь может сам писать, проверять и принимать код без программиста

ИИ-программистам теперь можно поручить ещё и работу тех, кто за ними проверяет код.

23 ноября **Anthropic** представила **Claude Ship**. Система позволяет автоматизировать проверку изменений в программах, исправление найденных ошибок и одобрение готового кода для включения в основную версию проекта.

## Три нейросети вместо отдела проверки

Работу поделили между тремя ИИ-агентами:

- **Code Review** изучает написанный код и оставляет замечания.
- **PR Steward** исправляет ошибки, разбирается с проваленными тестами и устраняет конфликты между изменениями разных разработчиков.
- **Claude Approvals** решает, можно ли принять получившийся код без участия человека.

Правила такого отбора устанавливает сама команда разработчиков. Например, мелкие исправления можно доверить нейросети целиком, а изменения, затрагивающие безопасность программы, отправлять на обязательную проверку специалисту.

В **Claude Code** для этого появилась команда `/ship`. Программист может закончить работу над очередной задачей, запустить проверку и переключиться на другую.

## Anthropic уже испытала систему на себе

С июня по сентябрь в команде разработчиков Claude Code:

- **Более чем вдвое** выросло количество принятых изменений в коде.
- **Более чем на 40%** сократилась доля изменений, которые впоследствии пришлось отменять.

Claude Ship доступен пользователям корпоративных тарифов **Team и Enterprise**, работающим с GitHub. Агенты исправления и одобрения кода пока находятся в бета-версии. Их работа оплачивается в зависимости от количества обработанных токенов.
