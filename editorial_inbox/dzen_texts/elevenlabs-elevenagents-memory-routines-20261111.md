# ElevenLabs научит ИИ-операторов помнить клиентов и самим перезванивать

**ElevenLabs** 11 ноября анонсировала две будущие функции для платформы **ElevenAgents**: **Memory** позволит голосовым ИИ-операторам помнить предыдущие разговоры с клиентами, а **Routines** — самостоятельно выполнять поручения до и после звонков.

Разработчики приводят пример с абонентом телефонной компании. В марте человек сообщил, что собирается переезжать. Когда он снова позвонит в апреле, ИИ вспомнит об этом и предложит перенести услугу на новый адрес.

Memory будет работать с клиентами, прошедшими подтверждение личности. После каждого разговора агент сможет сохранять важные сведения: предпочтительный язык общения, удобное время для звонков, предстоящие события или особые пожелания.

При следующем обращении запись обновится, а устаревшая информация будет удалена.

Основная клиентская база компании останется в CRM — программе для учёта клиентов. Новая память дополнит её подробностями, для которых обычно нет отдельной графы.

## Сам позвонит и выполнит поручение

Вторая функция, Routines, позволит запускать последовательности действий до, во время и после разговора.

Среди примеров ElevenLabs — предварительная проверка ипотечной заявки с последующим обратным звонком через несколько минут. Другой сценарий касается медицинских учреждений: ИИ напомнит пациенту о приёме, а при появлении свободного времени предложит запись человеку из списка ожидания.

Агент сможет подключаться к рабочим системам компании, отправлять отчёты по электронной почте, обновлять сведения о клиентах и самостоятельно начинать звонки.
