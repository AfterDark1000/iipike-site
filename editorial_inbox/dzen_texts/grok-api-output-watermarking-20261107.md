# Grok начал вшивать невидимые метки в ответы через API

С 7 ноября **Grok** начал маркировать текстовые ответы семи своих моделей через API — интерфейс, позволяющий подключать нейросеть к сторонним приложениям. Метка незаметна для читателя: никаких специальных символов в тексте не появляется.

Разработчик Grok, компания **SpaceXSI** (ранее xAI), объясняет, что маркировка создаётся непосредственно во время генерации. Нейросеть немного изменяет выбор токенов — фрагментов текста, из которых складывается ответ. По этим статистическим особенностям позднее можно попытаться определить его происхождение.

Маркировка включена по умолчанию для Grok 4.7, 4.6, 4.5, 4.3 и трёх вариантов Grok 4.20. Она распространяется на обычные текстовые ответы, структурированные данные и даже аргументы, которые ИИ передаёт инструментам при выполнении задач.

Разработчик приложения может узнать, применялась ли маркировка к конкретному ответу, по техническому заголовку `x-watermark`. А вот проверить уже скопированный текст сложнее: для этого предусмотрена отдельная система обнаружения, доступ к которой предоставляют по заявке.

Причём даже такая проверка не всегда даст определённый ответ. Метод статистический, и чем короче текст, тем слабее сигнал. Система может заключить, что метка есть, что её нет, либо признать результат неопределённым.

Администраторы команд могут отключать маркировку для отдельных моделей через панель управления. Правда, некоторые модели могут быть заблокированы для отключения. Кроме того, администратор должен подтвердить наличие применимого правового исключения и принять ответственность за соблюдение требований к маркировке контента.

SpaceXSI объясняет внедрение необходимостью соблюдать европейский закон об искусственном интеллекте — **EU AI Act**. При этом разработчикам не требуется менять существующие запросы к API.

Документация с описанием механизма обновлена ещё 31 октября, а **7 ноября обозначено датой начала его применения**. Сведения относятся к API Grok; подтверждения аналогичной маркировки обычных разговоров на сайте и в приложении Grok в этом документе нет.
