# llama.cpp дошла до версии 1.0 и меняет правила обновлений

Разработчики **llama.cpp** 13 ноября выпустили версию **1.0.0** и объявили новые правила обновления проекта. Теперь изменения, нарушающие совместимость с другими программами, будут отражаться в номере версии.

Для инструмента, на котором построено множество приложений с локальным искусственным интеллектом, это существенная перемена.

**llama.cpp** — открытый программный движок, позволяющий запускать нейросети на собственном компьютере или сервере. Он поддерживает разные модели, процессоры и видеокарты. Благодаря таким инструментам для работы с ИИ необязательно отправлять запросы в облако.

Проект развивается уже три с половиной года. За это время вокруг него выросла целая экосистема приложений, но частые изменения программных интерфейсов создавали разработчикам дополнительные хлопоты.

Теперь команда решила навести порядок.

## Что означает версия 1.0

Создатели llama.cpp и связанной с ней вычислительной библиотеки **ggml** перешли на семантическую нумерацию версий.

Если обновление добавляет совместимую функцию, меняется средняя цифра номера. Если исправляет ошибку — последняя. А изменения, после которых старый код может перестать работать, требуют новой основной версии.

Например, разработчик сможет по номеру обновления понять, стоит ли заранее проверять совместимость своего приложения.

Правда, сам переход на 1.0 начался с большой уборки. Из llama.cpp удалили **35 устаревших функций** программного интерфейса и другие элементы, которые команда больше не намерена поддерживать. Поэтому некоторым приложениям для перехода на новую версию может потребоваться доработка.

## Что ещё появилось в релизе

Обновление не ограничилось новой нумерацией.

В движок добавили поддержку **FP8-кеша**. Это способ хранить часть промежуточных вычислений нейросети в компактном формате, позволяющий экономить память при работе с длинными запросами. Конкретный выигрыш зависит от модели и настроек.

Улучшена работа с моделями, использующими архитектуру *Mixture of Experts*: часть необходимых вычислительных данных теперь можно эффективнее хранить в оперативной памяти.

Расширилась поддержка текстовых, зрительных и голосовых моделей. Сервер получил новый интерфейс для синтеза речи, а его защиту усилили от нескольких типов сетевых атак.

Изменился и встроенный веб-интерфейс: появились группы чатов, более удобная работа с длинными сообщениями и редактор Markdown.

Для обычного пользователя номер 1.0 сам по себе не означает ускорения любимой нейросети. Главное обещание разработчиков касается предсказуемости дальнейших обновлений — чтобы приложения, использующие llama.cpp, было проще поддерживать.

Версия **1.0.0** уже опубликована в официальном репозитории GitHub. Одновременно разработчики выпустили **ggml 1.0.0**, закрепив общие правила совместимости для обеих библиотек.
