# Хакеры взломали Cursor через чужой ключ и добрались до 5000 пользователей

**Cursor** выяснила, как злоумышленники проникли в её системы и сумели подменить расширение **Claude Code** в магазине редактора. Входом послужил ключ доступа, который компания выдала своему партнёру **Fireworks AI** для работы с ИИ-моделями.

13 ноября Cursor опубликовала результаты двухнедельного расследования октябрьского взлома. Выяснилось, что история с заражённым расширением была последним звеном гораздо более длинной атаки.

## Сначала украли данные, потом добрались до магазина

Ключ доступа оказался раскрыт на стороне Fireworks. С его помощью злоумышленник скопировал данные из хранилища, которое Cursor использовала для обмена информацией с партнёром.

Там находились записи работы ИИ-агентов, преимущественно за 2025 год. Они относились к сеансам, в которых пользователи не включали Privacy Mode — режим повышенной конфиденциальности.

В некоторых записях сохранились незамаскированные ключи доступа. Используя их, атакующий проник в отдельные сторонние сервисы Cursor и получил доступ к архивным репозиториям исходного кода, части переписки службы поддержки, контактным данным клиентов и сведениям об использовании продуктов.

Затем злоумышленник добрался до инфраструктуры магазина расширений.

29 октября злоумышленник [подменил расширение Claude Code в магазине Cursor](https://dzen.ru/a/auS74dc3hhANV18_). Вредоносные версии 2.1.312 и 2.1.313 пытались установить скрытый доступ к компьютерам разработчиков через SSH.

Подмена продержалась около 11 часов. По оценке Cursor, заражённую версию могли получить не более 5000 пользователей.

## Сколько данных утекло

Cursor раскрыла масштабы нескольких отдельных последствий:

- Менее 0,05% пользователей — их записи работы ИИ-агентов попали в утечку.
- Менее 0,01% клиентов — у них оказались раскрыты API-ключи.
- До 5000 пользователей могли получить заражённое расширение из магазина Cursor.

Компания утверждает, что уведомила непосредственно затронутых клиентов. Репозитории пользовательского кода, рабочая инфраструктура Cursor и запросы пользователей с включённым Privacy Mode, согласно результатам расследования, не пострадали.

После обнаружения атаки Cursor отозвала и заменила ключи доступа, перестроила магазин расширений, повторно развернула производственную инфраструктуру и полностью прекратила передачу запросов на обработку через Fireworks.

Последнюю активность злоумышленника зафиксировали 1 ноября — её удалось заблокировать. По состоянию на 13 ноября Cursor считает инцидент локализованным.

Пользователям, установившим подозрительные версии Claude Code из магазина Cursor 29 октября, компания рекомендует выполнить проверку по опубликованной инструкции: обычного удаления расширения может оказаться недостаточно.
