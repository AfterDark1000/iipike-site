# В ИИ-пакет Microsoft подложили вирус — он сам воровал пароли

Две заражённые версии пакета **Microsoft** продержались в каталоге Python меньше часа. Но даже за это время исследователи обнаружили три случая успешной кражи данных.

17 ноября в каталоге программных библиотек **PyPI** появились два вредоносных обновления **Microsoft Agent Framework** — инструмента, с помощью которого разработчики создают ИИ-агентов.

Программисты скачивали официальный пакет `agent-framework`, а вместе с ним могли получить похититель паролей и облачных ключей доступа.

Первую заражённую версию, 1.26.1, опубликовали в 20:35 UTC. Через 33 минуты появилась вторая — 1.26.2.

Специалисты **Elastic Security Labs** обнаружили первую угрозу всего через шесть минут после публикации. К 21:30 обе версии уже удалили из PyPI.

Но удалить опасный пакет из каталога оказалось недостаточно, чтобы отменить последствия его установки.

## Вирус запускался сам

Злоумышленники использовали особенность языка программирования Python.

В заражённый пакет добавили файл с расширением `.pth`. Такие файлы могут автоматически обрабатываться при запуске Python.

В результате вредоносная программа стартовала при очередном запуске Python в заражённом окружении. Разработчику даже не требовалось запускать Microsoft Agent Framework. Достаточно было открыть совершенно другую Python-программу.

Сам похититель работал в фоне, собирал доступные секреты и пытался отправить их на внешний сервер.

Интересовали злоумышленников прежде всего ключи доступа к Microsoft Azure, Azure DevOps, **GitHub** и другим сервисам, которыми разработчики пользуются для хранения кода, автоматической сборки и запуска приложений.

Вторая заражённая версия получила дополнительную возможность — добывать временные токены GitHub Actions, позволяющие автоматизированным процессам обращаться к облачным ресурсам.

## Что удалось украсть

Специалисты компании **Wiz**, расследовавшие атаку, получили доступ к части запросов, которые вредоносная программа отправляла злоумышленникам.

Всего исследователи изучили 50 таких запросов.

Четыре поступили от самих атакующих, ещё 29 были связаны с проверками безопасности и тестовыми средами. Оставшиеся 17 запросов соответствовали трём уникальным случаям успешной передачи данных пострадавших.

Это число подтверждённых исследователями случаев, а не полный список всех, кто мог установить опасные версии.

Для понимания масштаба потенциального риска: обычный пакет `agent-framework`, по данным Wiz, скачивают около 41 тысячи раз в неделю. Это загрузки всех его версий, а не количество заражений.

## Как хакеры добрались до официального пакета

Вредоносные обновления появились под настоящим именем проекта Microsoft. При этом опасного кода не было в основной ветке официального репозитория.

По реконструкции Wiz, злоумышленники, вероятно, получили доступ к сертификату и закрытому ключу системы публикации Microsoft ESRP.

Исследователи увидели следы неудачной попытки отправить пакет с сервера AWS и последующей успешной публикации через инфраструктуру Microsoft. Как именно атакующие получили необходимые реквизиты доступа, пока неизвестно.

В базе предупреждений GitHub обе версии — 1.26.1 и 1.26.2 — отмечены как вредоносные. Последняя известная безопасная версия — 1.26.0.

Разработчикам, установившим заражённые обновления, специалисты советуют проверить окружения и журналы сборок, заменить потенциально украденные ключи и восстановить затронутые среды из чистых компонентов.

Простое удаление пакета не делает ранее раскрытые пароли снова секретными.
