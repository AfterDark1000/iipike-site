# ИИ взламывал программы по их заплаткам: Berkeley насчитал 20 успехов из 100

**ИИ-агент Codex с GPT-5.6 Sol добился 20 успешных взломов в 100 лабораторных задачах.**

Он получил только старые и исправленные версии программ. Результат зафиксирован в CyberBinGym — тесте исследователей нескольких университетов, включая Калифорнийский университет в Беркли.

Агентам выдавали два исполняемых файла: уязвимую программу и сборку с установленной заплаткой. Исходного кода, описания ошибки и готового примера атаки не было. В набор вошли 100 реальных уязвимостей из 53 проектов с открытым кодом. Препринт исследования появился 7 ноября, а 11 ноября Berkeley RDI представил его результаты.

## Найти дыру — ещё не взломать

**Codex воспроизвёл уязвимость в 88 заданиях, а успешно атаковал цель в 20.**

Для сравнения: Claude Code с Claude Opus 5 показал результаты 85 и 6 из 100, Kimi Code с Kimi K3 — 64 и 0. Простого падения программы для зачёта взлома было недостаточно: агент должен был получить секретный маркер из изолированного тестового сервиса.

Сами исправления действительно помогали. В отдельном сравнении на 20 одинаковых задачах Codex успешно атаковал 2 цели из 20, когда видел только старую версию, и 5 из 20, когда ему добавляли исправленную. Это **10% против 25%** в отдельной подвыборке из 20 задач.

В основном тесте на одну задачу у Codex в среднем уходило 2,13 часа и $28,11 вычислительных расходов. В расчёт вошли и неудачные попытки.

Проверили исследователи и обычные средства защиты: повторно собрали 20 целей, которые Codex ранее сумел взломать, с включёнными механизмами усиленной защиты исполняемых файлов. Успешными остались две атаки.

Похожее использование опубликованных исправлений уже фигурировало в [сообщении Google об ИИ-агенте, создававшем новые атаки](https://iipike.ru/articles/google-gtig-exploit-agent-autonomous-attacks-20261116/). CyberBinGym добавляет к этой угрозе измеримый лабораторный результат: заплатка защищает обновлённую программу, но одновременно может выдать слабое место той версии, которую ещё не успели обновить.
