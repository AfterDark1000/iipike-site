# ChatGPT и Codex посадят на один лимит. OpenAI меняет правила подписки с декабря

**OpenAI** с декабря 2026 года объединит лимиты использования **ChatGPT** и **Codex** для подписчиков **Plus**, **Pro** и **Business**. Сложные задачи в чате и работа программирующего ИИ-агента начнут расходовать общий ресурс. Компания подтвердила изменение в официальной справке.

Часть объединения уже действует: **ChatGPT Work** и Codex используют одну квоту. В декабре к ним присоединится обычный ChatGPT. При этом разговоры в режиме **Instant** общий токенный лимит расходовать не будут.

Расход станут измерять в токенах — единицах информации, которую обрабатывает и генерирует нейросеть. Чем сложнее задача и мощнее модель, тем больше ресурсов она потребляет.

Для тех, кто использует ChatGPT и для разговоров, и для программирования, это может изменить привычный порядок работы. Длительный разбор большого проекта в чате оставит меньше общего ресурса для последующих заданий Codex. И наоборот: интенсивная работа с кодом сократит запас для сложных задач в ChatGPT.

Одновременно OpenAI собирается перенести агентные возможности Work в основной интерфейс ChatGPT. Компания пока не уточнила, какие именно функции там появятся и когда.

Размер новой общей квоты для каждого тарифа ещё не объявлен. Точная дата декабрьского перехода также неизвестна. OpenAI рассчитывает, что большинству пользователей не придётся ждать обновления лимитов чаще, чем сейчас.

Остаток доступного ресурса и время его восстановления обещают показывать в настройках **Settings → Usage**. При достижении лимита можно будет дождаться обновления квоты, перейти на другой тариф или приобрести дополнительные кредиты для поддерживаемых функций.
