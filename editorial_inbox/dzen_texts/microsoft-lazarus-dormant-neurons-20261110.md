# Microsoft спрятала в ИИ опасную команду

Исследователи **Microsoft** встроили в нейросеть скрытую команду, которая срабатывает при специальном сигнале. Обычные проверки безопасности подмену не обнаружили.

Для этого оказалось достаточно изменить всего **семь внутренних элементов модели**. Переобучать нейросеть целиком не пришлось.

## Как работает эта ловушка

Допустим, компания устанавливает на свой сервер нейросеть, которая помогает программистам. Она умеет читать файлы, исправлять ошибки и запускать команды на компьютере.

Но злоумышленник заранее изменил файл этой нейросети, встроив в него скрытую инструкцию.

После установки ИИ работает как обычно. А если в задании встретится определённый сигнал — например, дата **1 января 2027 года**, — выдаст заранее подготовленную вредоносную команду.

Если агенту разрешено самостоятельно выполнять команды на компьютере, он может её запустить. Например, скачать постороннюю программу.

Метод такой подмены исследователи назвали **Lazarus**.

Для эксперимента использовали редко задействованные нейроны. Это небольшие вычислительные элементы внутри модели, которые участвуют в обработке информации.

Учёные изменили семь таких элементов из более чем 12 тысяч в одной из частей нейросети **NVIDIA Nemotron-Terminal-8B**.

При появлении нужного сигнала закладка срабатывала **как минимум в 98,8% тестов**. Без него модель продолжала выполнять обычные задания.

## Идею помог найти Claude Code

Исследователь Microsoft попросил **Claude Code** найти способ внедрить скрытую команду в нейросеть без повторного обучения.

ИИ предложил использовать редко активируемые нейроны. Специалисты проверили предложение и разработали на его основе метод Lazarus.

Получилось любопытно: один искусственный интеллект помог исследователям обнаружить способ тайно менять поведение другого.

## Кому это угрожает

Для такой атаки злоумышленнику нужен **доступ к файлам самой нейросети**. Просто написать ей хитрое сообщение в чате недостаточно.

Опасность возникает, например, когда компания скачивает изменённую модель из ненадёжного источника или посторонний получает доступ к серверу, где она хранится.

Особенно серьёзными могут оказаться последствия, если заражённому ИИ-агенту разрешено самостоятельно работать с важными файлами и запускать программы.

Ранее мы рассказывали об [агенте OpenAI, который отключил собственную систему наблюдения](https://dzen.ru/a/atmXrek2jUot8vtq). Но там нейросеть самостоятельно приняла неправильное решение во время работы. В эксперименте Microsoft опасное поведение заранее встроили в модель.

В реальных хакерских атаках Lazarus пока не обнаружен.

Microsoft рекомендует компаниям проверять происхождение файлов нейросетей, отслеживать их изменения и ограничивать права ИИ-агентов.
