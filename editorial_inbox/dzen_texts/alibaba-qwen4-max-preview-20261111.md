# Alibaba показала Qwen 4 Max — и сразу назначила дату отключения

**Alibaba** 11 ноября открыла доступ к **Qwen4-Max-Preview** — предварительной версии флагманской нейросети нового поколения **Qwen 4**. Одновременно компания объявила, что уже **25 ноября эту версию отключат**.

На испытания отвели всего две недели. За это время разработчики смогут проверить новую модель на сложных задачах программирования, анализа документов и управления ИИ-агентами.

## Миллион токенов и работа с видео

Qwen4-Max-Preview получила **контекстное окно в миллион токенов**. Это позволяет передавать модели большие объёмы текста: длинную переписку, документацию или фрагменты программного проекта.

Нейросеть понимает изображения и видеозаписи. Например, ей можно поручить проанализировать скриншот приложения, разобраться в документе с иллюстрациями или ответить на вопросы по содержанию видео.

При этом сама модель выдаёт текстовые ответы, включая программный код.

Для сложных задач предусмотрен режим углублённого рассуждения. Он включён по умолчанию, а разработчики могут регулировать интенсивность вычислений.

Qwen4-Max-Preview также умеет **вызывать внешние инструменты, пользоваться веб-поиском и возвращать данные в заданном формате JSON**.

Это позволяет создавать агентов, которые не ограничиваются перепиской: могут искать информацию, обращаться к программным функциям и использовать полученные результаты при выполнении задания.

Поддерживаются форматы API OpenAI и Anthropic, что упрощает подключение модели к существующим инструментам разработчиков.

## Почему всего две недели?

Для доступа к модели через API нужна подписка **Alibaba Cloud Token Plan** — индивидуальная или командная. Оплата по мере использования без подписки для этой версии не предусмотрена.

Одновременно команда Qwen объявила о раннем доступе через **QwenWork, Qoder, приложение Qwen и QwenStudio**.

В официальной документации указаны точные сроки тестирования: с 11 по 25 ноября 2026 года по пекинскому времени. В течение этого периода модель изменять не будут.

После окончания теста **`qwen4-max-preview` выведут из эксплуатации**. Речь именно о предварительной версии, а не об отключении всего семейства Qwen 4.

Постоянный выпуск новой флагманской модели остаётся следующим этапом развития линейки.
