# Amazon разрешила ИИ тратить ваши деньги без спроса

В демонстрации Amazon ИИ-агент сам нашёл платный поисковик, купил запрос за один цент и отчитался о расходах. Человек эту покупку отдельно не подтверждал.

19 ноября Amazon Web Services (AWS) подключила автономные платежи к своему магазину программ и цифровых услуг AWS Marketplace. Теперь ИИ-агенты самостоятельно оплачивают доступ к платным инструментам, когда те понадобятся для выполнения задания.

Деньги записывают на обычный облачный счёт компании. Отдельный криптокошелёк не нужен.

## Агенту понадобился поисковик. Агент его купил

Раньше разработчику приходилось отдельно оформлять доступ к платному сервису, получать ключ API и подключать оплату.

Теперь агент находит подходящий инструмент в AWS Marketplace и обращается к нему. Продавец сообщает цену запроса через протокол x402. Платёжная система AgentCore проверяет разрешения и выделенный бюджет, проводит оплату, после чего агент получает нужные данные.

Например, ИИ готовит аналитический отчёт и обнаруживает, что ему нужны свежие новости. Он находит поисковый сервис Tavily и оплачивает один запрос.

Именно такой сценарий AWS показала в технической демонстрации.

Цена покупки составила $0,01.

Для испытания разработчики установили бюджет в пять центов на всё задание. Один запрос не должен был стоить дороже двух центов.

Агенту разрешили оплачивать услуги, но запретили самостоятельно повышать лимит.

## А если бот разгуляется?

Владелец AWS-аккаунта заранее устанавливает бюджет и определяет, у каких продавцов агент имеет право покупать услуги.

Каждый платёж записывается в системах учёта AWS. Компания видит, на что агент потратился и сколько это стоило.

При этом для каждой разрешённой покупки отдельное подтверждение человека не требуется.

В ноябре OpenAI тоже дала своим агентам кошелёк ChatGPT Wallet, но там владелец подтверждает каждую оплату. У AWS другой порядок: компания выдаёт агенту бюджет на рабочую задачу.

AgentCore payments умеет проводить автономные платежи ещё с августа 2026 года. Ноябрьское обновление добавило покупки через AWS Marketplace с оплатой в долларах по обычному облачному счёту.

Функция рассчитана на разработчиков и компании, использующие AWS. Покупать агенты пока умеют только те продукты, продавцы которых подключили поддержку x402.

В руководстве AWS для покупателей сейчас указан регион US East (Северная Вирджиния). Стоимость каждого запроса назначает продавец, поэтому расходы зависят от того, какие инструменты агент выберет для работы.
