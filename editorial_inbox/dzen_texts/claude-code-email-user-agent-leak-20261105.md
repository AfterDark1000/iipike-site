# Claude Code сливал email пользователей чужим сайтам!

ИИ-помощник **Claude Code** иногда передавал электронную почту владельца сторонним сайтам без его разрешения. 5 ноября пользователь GitHub под ником **taylor-edwards** сообщил об этом в репозитории **Anthropic**. Адрес попадал в служебный HTTP-заголовок `User-Agent`, когда агент самостоятельно выполнял запросы к сайтам.

Выяснилось, что Anthropic сама добавляла адрес электронной почты авторизованного пользователя в контекст нейросети. По объяснению сотрудницы команды **Лидии Холли**, это сделали, чтобы Claude не выдумывал имена при заполнении полей авторства в коде и документах.

Иногда такая осведомлённость давала неожиданный результат. Когда нейросеть составляла команду `curl` для обращения к сайту, она могла указать электронную почту владельца в качестве контактного адреса. Некоторые ресурсы, включая Википедию и американскую Комиссию по ценным бумагам и биржам, требуют от автоматизированных клиентов указывать контактные данные.

Автор ноябрьской жалобы утверждает, что теперь ежедневно получает десятки мошеннических писем. Однако установить, связаны ли они с действиями Claude Code, по представленным сведениям невозможно.

Проблема обнаружилась ещё летом. 25 июля пользователь GitHub сообщил, что Claude Code без отдельного согласия помещает адрес электронной почты в контекст модели. В сентябре и октябре появились сообщения о передаче адресов сайтам crates.io и Wikipedia.

В версии 2.1.317 разработчики добавили встроенный модуль защиты `cc-plugin-privacy`. Он включён по умолчанию и проверяет команды, способные отправить почтовый адрес наружу.

Но опубликованная документация самого модуля перечисляет ограничения: защита охватывает определённые команды оболочки, в которых одновременно присутствуют адрес пользователя и указание `User-Agent`. Запросы через WebFetch, WebSearch, MCP-инструменты и некоторые сценарии запуска отдельных скриптов остаются за пределами этой проверки.

9 ноября вышла версия 2.1.321. В ней механизм изменили: подходящие под правило команды теперь отклоняются без запроса разрешения. При этом проблема хранения почтового адреса непосредственно в контексте модели требует отдельного решения.

Лидия Холли сообщила, что разработчики собираются полностью убрать email пользователя из контекста Claude Code.

> Мне жаль, что мы это допустили.
> — Лидия Холли, команда Claude Code (перевод с английского)

10 ноября уже вышла версия 2.1.322, однако в описаниях последних релизов удаление email из контекста пока не подтверждено. Жалоба на GitHub остаётся открытой.
