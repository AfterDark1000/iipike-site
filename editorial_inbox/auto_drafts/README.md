# ХПИИ — хранилище неутверждённых автодрафтов

Этот каталог предназначен **только** для будущего автоматического редактора ChatGPT. Каждый материал хранится в `<article_id>.json` и привязан к подтверждённому резерву в `main/data/auto_editor/receipts/`. Схема и правила: `main/scripts/auto_editor_workbench.py` и `main/docs/AUTO_EDITOR_STAGE2.md`.

**Не** создавать здесь `editor_approved`, не переносить документы в `editorial_inbox/stories/` до явного решения главного редактора. Отсутствие файлов JSON означает, что черновиков пока нет. Этот каталог не запускает публикацию.
