## Как обновляется страница

После каждого запуска штатного GitHub-планировщика программа сверяет две ветки: опубликованный архив `main` и редакционную очередь `editorial-intake`. Изменения автоматически записываются сюда, если статусы поменялись.

**[Запуски планировщика](https://github.com/AfterDark1000/iipike-site/actions/workflows/site-first-scheduled-release.yml)** · **[Правила очереди](https://github.com/AfterDark1000/iipike-site/blob/main/editorial_inbox/SITE_PUBLICATION_QUEUE.md)**

Чтобы проверить очередь, не публикуя ничего, вручную запустите `HPII — site-first scheduled hourly queue` с `inspect_only=true`.

_Начальная таблица сверена редактором вручную после установки; следующие изменения должен выполнять планировщик. GitHub не обещает запуск cron с точностью до секунды. Для закрытой админки потребуется авторизация._
